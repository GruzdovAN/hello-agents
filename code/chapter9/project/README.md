# Демо-каталог проекта

Этот каталог используется для демонстрации функций безопасности TerminalTool.

## проиллюстрировать

TerminalTool имеет следующие функции безопасности:

1. **Белый список команд**: разрешает выполнение только определенных команд безопасности.
2. **Ограничение рабочего каталога**: файлы за пределами рабочего каталога недоступны.
3. **Защита от обхода пути**: предотвращение выхода из рабочего каталога с помощью `..` и других методов.

## Тестовый сценарий

- Попытки выполнить опасные команды (например, `rm -rf`) будут заблокированы.
- Попытки доступа к файлам за пределами рабочего каталога будут запрещены.
- Попытки выйти из рабочего каталога по относительным путям будут обнаружены и заблокированы.
