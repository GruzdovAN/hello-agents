# 💖 Руководство пользователя системы благосклонности NPC

## 📚 Обзор

У NPC в Кибер-городе теперь есть **система благосклонности**, которая может автоматически регулировать их благосклонность в зависимости от содержания разговора с игроком и влиять на стиль и отношение последующих разговоров!

---

## ✨ Основные функции

### 1. **Автоматический анализ настроений**
- 🤖 Используйте LLM Agent для анализа настроений в разговоре.
- 📊 Определить отношение игрока (дружественное/нейтральное/недружественное)
- 🎯 Оцените качество разговора (глубокий/средний/поверхностный)
- 💬 Выявить эмоциональные тенденции (хвала/критика/нейтральность)

### 2. **Динамическая настройка предпочтений**
- 📈 Дружеские разговоры повышают благосклонность (от +1 до +10)
- 📉 Критические разговоры снижают благосклонность (от -3 до -15)
- 🔄 Автоматически обновлять значение предпочтительности (0–100)
- 🎚️Ограничено в разумных пределах.

### 3. **Система уровней отношений**
- 🥶 **Странно** (0-20): Холодный и отстраненный, не желающий много говорить.
- 😐 **Знакомый** (20–40): Вежливый, но немного незнакомый.
- 😊 **Дружелюбие** (40-60): Вежливое и дружелюбное, нормальное общение.
- 🤗 **Интимный** (60–80): Дружелюбный и полный энтузиазма, готовы больше общаться.
- 💕 **Лучший друг** (80–100): полон энтузиазма, как старый друг.

### 4. **Настройка стиля разговора**
- 🎭 Благосклонность влияет на стиль разговора NPC.
- 💬 Высокая благосклонность: больше энтузиазма и желания поделиться
- 😶 Низкая благосклонность: более холодные и короткие ответы
- 🔄 Динамическая настройка, эффективная в режиме реального времени

## 🎯 Пример использования

### Пример 1: Повышение благосклонности

```
Начальная благосклонность: 50 (дружественная)

Первый разговор:
Игрок: «Привет, приятно познакомиться!»
Чжан Сан: «Привет! Мне тоже приятно познакомиться».
📈 Благосклонность: 50 -> 55 (дружеский привет)

Второй разговор:
Игрок: «Ваш код потрясающий!»
Чжан Сан: «Спасибо! Недавно я изучал новые технологии. Вас это интересует?»
📈 Благоприятность: 55 -> 63 (работа с похвалой) → Повышение уровня отношений: Дружелюбие -> Близость.

Третий разговор:
Игрок: «Можете ли вы меня научить?»
Чжан Сан: «Конечно! Буду рад поделиться. С чего вы хотите начать?»
📈 Благоприятность: 63 -> 69 (спросите совета и узнайте)
```

### Пример 2: Снижение благосклонности

```
Текущая благосклонность: 69 (близость)

Критический диалог:
Игрок: «У тебя такой плохой код!»
Чжан Сан: «Извините, я исправлюсь…»
📉 Благоприятность: 69 -> 61 (Критика работы) → Снижение уровня отношений: Близость -> Дружелюбие
```

### Пример 3: Изменение стиля разговора

```
Благосклонность: 30 (знакомый)
Игрок: «Привет, как дела?»
Джон Доу: «Все в порядке». (короткий ответ)

Благоприятность: 70 (близость)
Игрок: «Привет, как дела?»
Ли Си: «Очень хорошо! Недавно я работаю над очень интересным проектом. Хотите его послушать?» (восторженно и подробно)

Благосклонность: 90 (лучший друг)
Игрок: «Привет, как дела?»
Ли Си: «Ха-ха, старый друг! В последнее время я был очень занят, но очень приносил удовлетворение. Кстати, я нашел ответ на вопрос, который ты задал в прошлый раз!» (добрый и инициативный)
```

## 🔧 Техническая реализация

### Архитектурный дизайн

```
RelationshipManager
├── affinity_scores: Dict[str, Dict[str, float]]  # Хранилище благосклонности NPC
├── analyzer_agent: SimpleAgent                   # Агент анализа настроений
├── get_affinity(npc_name, player_id)            # Получите благосклонность
├── analyze_and_update_affinity(...)             # Анализируйте и обновляйте благоприятность
├── get_affinity_level(affinity)                 # Получить уровень отношений
└── get_affinity_modifier(affinity)              # Получить модификаторы разговорного стиля
```

### Процесс анализа настроений

```
1. Игрок отправляет сообщение
   ↓
2. NPC генерирует ответ
   ↓
3. Агент анализа настроений анализирует разговоры
   ├── Анализируйте отношение игроков
   ├── Оцените содержание разговора
   ├── Определить эмоциональные склонности
   └── Рассчитайте изменение благоприятности
   ↓
4. Обновить предпочтения
   ├── Текущая выгода + сумма изменения
   ├── Ограничение в диапазоне 0–100
   └── Проверьте изменения уровня
   ↓
5. Сохранить в память системы
   └── Записывайте благоприятную и эмоциональную информацию.
```

### Правила изменения предпочтений

| Тип разговора | Вариация | Пример |
|---------|--------|------|
| Хвалю, благодарю, прошу совета | от +3 до +8 | "Ты обалденный!" "Спасибо!" «Можете ли вы научить меня?» |
| Дружеский привет, нормальное общение | от +1 до +3 | "Привет!" "Как дела?" |
| Общий чат, нейтральные темы | 0 | «Погода сегодня хорошая» |
| Критика, сомнения, нетерпение | от -3 до -8 | «Это нехорошо» «Правда?» |
| Оскорбление, нападение, злоба | от -8 до -15 | "Ты полный отстой!" |

## 📊 Конфигурация системы предпочтений

### Слова-подсказки для анализа настроений

Агент анализа настроений использует тщательно разработанные слова-подсказки для анализа разговоров:

```python
[Измерение анализа]
1. Отношение игрока: Дружелюбное/Нейтральное/Недружелюбное
2. Содержание разговора: Положительное/Нейтральное/Отрицательное.
3. Качество взаимодействия: Глубокое/Посредственное/Поверхностное.
4. Эмоциональные тенденции: похвала/критика/нейтральность.

[Формат вывода]
{
    "should_change": true/false,
    «change_amount»: целое число от -15 до +10,
    "reason": "Кратко опишите причину",
    "sentiment": "positive/neutral/negative"
}
```

### Рекомендации по настройке

Если вы хотите настроить чувствительность к изменениям предпочтений, вы можете изменить слова подсказки в `relationship_manager.py`:

- **Более чувствительно**: увеличьте диапазон изменения (например: от -20 до +15).
- **Более консервативный**: уменьшите диапазон изменений (например: от -5 до +5).
- **Более подробно**: добавьте дополнительные параметры анализа.
- **Проще**: упрощенные правила анализа.

## ❓ Часто задаваемые вопросы

### Вопрос 1: Почему уровень благосклонности не изменился?

**Возможные причины:**
- Содержание разговора слишком нейтрально.
- Агент анализа настроений определяет, что никаких изменений не требуется.
- Не удалось проанализировать ответ LLM.

**Решение:**
- Используйте более ясные выражения эмоций.
- Проверьте результаты анализа настроений в журналах.
- Отрегулируйте слова подсказки для анализа настроений

### Вопрос 2: Изменяется ли благосклонность слишком быстро/слишком медленно?

**Решение:**
- Измените диапазон вариаций в `relationship_manager.py`.
- Настройте правила в подсказках для анализа настроений.
— Вручную установите начальное значение с помощью set_npc_affinity.

### Вопрос 3: Нет ли очевидных изменений в стиле разговора?

**Возможные причины:**
- Разница в благоприятности недостаточно велика
- System_prompt NPC не полностью использует модификатор благосклонности.

**Решение:**
- Увеличить разницу в благосклонности (например: 20 против 80)
- Подчеркните важность разговорного стиля в system_prompt.
