Диалоговая система #cybertown-AI NPC

Игра-симулятор города с искусственным интеллектом, основанная на платформе HelloAgents, демонстрирующая применение мультиагентных систем в играх.

## 🎮 Особенности

- ✅ 3 AI NPC (Чжан Сан, Ли Си, Ван Ву)
- ✅ Интеллектуальная диалоговая система
- ✅Система памяти (краткосрочная + долговременная память)
- ✅ Система благосклонности (5 уровней)
- ✅ Автономное поведение NPC (тусуются, работают)
- ✅ Полная система журналов

## 🛠️ Стек технологий

- **Игровой движок:** Godot 4.x
- **Backend Framework:** FastAPI + Python 3.10+.
- **AI Framework:** HelloAgents
- **LLM:** OpenAI GPT-4 (можно настраивать другие службы LLM)
