# Кибергород – Руководство по установке и настройке

## 📋 Системные требования

- **Операционная система:** Windows 10/11, macOS, Linux.
- **Годо:** 4,2+ (рекомендуется 4,3)
- **Питон:** 3.10+
- **Git:** (необязательно, для клонирования проекта)

## 🚀 Этапы установки

### Шаг 1: Загрузите проект

**Метод А: использование Git**```bash
git clone https://github.com/datawhalechina/hello-agents
cd chapter15
```

**Метод Б: Загрузите ZIP-архив**
1. Загрузите ZIP-файл проекта.
2. Разархивируйте в любую директорию.

### Шаг 2: Установите Годо

1. Посетите [официальный сайт Godot](https://godotengine.org/download).
2. Загрузите версию Godot 4.2+.
3. Разархивируйте и запустите Godot.

### Шаг 3. Настройте среду Python

#### 3.1 Создание виртуальной среды```bash
cd backend
python -m venv venv
```

#### 3.2 Активация виртуальной среды
**Окна:**```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

#### 3.3 Установка зависимостей```bash
pip install -r requirements.txt
```

#### 3.4 Установка HelloAgents```bash
cd ../HelloAgents
pip install -e .
cd ../backend
```

### Шаг 4. Настройте переменные среды

#### 4.1 Копирование файлов переменных среды```bash
cp .env.example .env
```

#### 4.2 Редактирование файла .env```env
# Конфигурация API
API_HOST=0.0.0.0
API_PORT=8000

# Конфигурация LLM — введите свой ключ API
LLM_API_KEY=sk-your-api-key-here
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4

# Интервал обновления NPC (секунды)
NPC_UPDATE_INTERVAL=30
```

**Важно!** Замените `LLM_API_KEY` своим действительным ключом API!

### Шаг 5. Запустите серверную службу

```bash
cd backend
python main.py
```

### Шаг 6. Откройте проект Godot

1. Запустите Годо
2. Нажмите «Импортировать».
3. Выберите «Helloagents-AI-Town/helloagents-ai-town/scenes/main.tscn».
4. Нажмите «Импортировать и редактировать».

### Шаг 7: Запустите игру

1. В редакторе Godot нажмите кнопку «Выполнить» в правом верхнем углу (или нажмите F5)
2. Должно открыться окно игры.
3. Используйте WASD для перемещения и клавишу E для взаимодействия с NPC.

## 🎮 Работа игры

- **WASD** — мобильные игроки
- **E** - Взаимодействие с NPC
- **Ввести** - Отправить сообщение
- **ESC** — закрывает диалоговое окно.

## ❓ Часто задаваемые вопросы

### Q1: Не удалось запустить серверную часть?
**А:** Проверьте:
1. Версия Python>=3.10?
2. Активирована ли виртуальная среда
3. Все ли зависимости установлены?
4. Правильно ли настроен файл .env?

### В2: Годо не может открыть проект?
**А:** Проверьте:
1. Версия Годо >=4.2?
2. Существует ли файл project.godot?
3. Правильно ли вы выбрали каталог?

### Q3: Игра запущена, но разговаривать невозможно?
**А:** Проверьте:
1. Работает ли серверная служба?
2. Правильный ли внутренний адрес (по умолчанию http://localhost:8000)
3. Проверьте консоль Godot на наличие сообщений об ошибках.
