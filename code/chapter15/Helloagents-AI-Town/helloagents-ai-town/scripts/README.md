# 🎮 Кибергород — Инструкции по сценарию GDScript

```
scripts/

## 📄 Подробное объяснение скрипта

### 1. config.gd (глобальная конфигурация)
**Цель**: хранить глобальные константы и конфигурации.

**Конфигурация ключей**:```gdscript
const API_BASE_URL = "http://localhost:8000"  # Адрес внутреннего API
const PLAYER_SPEED = 200.0                     # скорость игрока
const NPC_STATUS_UPDATE_INTERVAL = 30.0        # Интервал обновления NPC
```

**Как использовать**:```gdscript
# доступ в любом скрипте
Config.log_info("информация")
var speed = Config.PLAYER_SPEED
```

---

### 2. api_client.gd (API-клиент)
**Цель**: взаимодействие с серверной частью FastAPI.

**Основные методы**:
- `send_chat(npc_name, message)` - Отправить чат
- `get_npc_status()` - Получить статус NPC
- `get_npc_list()` - Получить список NPC

**Сигнал**:
- `chat_response_received(npc_name, message)` - Получен ответ на диалог
- `chat_error(error_message)` - Ошибка чата
- `npc_status_received(диалоги)` - получен статус NPC

**Пример использования**:```gdscript
# Получить API-клиент
var api = get_node("/root/APIClient")

# Отправить разговор
api.send_chat("Чжан Сань", "Привет")

# Слушайте ответы
api.chat_response_received.connect(_on_response)

func _on_response(npc_name, message):
    print(npc_name + ": " + message)
```

---

### 3. player.gd (управление игроком)
**Цель**: управлять движением и взаимодействием игроков.

**Основные характеристики**:
- WASD/движение клавиши со стрелкой
-E клавиша для взаимодействия с NPC
- Обнаружение ближайших NPC

**Требования к узлу**:```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
└── Camera2D
```

**Пользовательские параметры**:```gdscript
@export var speed: float = 200.0  # Настраивается в Инспекторе
```

---

### 4. npc.gd (поведение NPC)
**Использование**: взаимодействие с NPC и отображение статуса.

**Основные характеристики**:
- Обнаружение игроков, входящих/выходящих из зоны взаимодействия.
- Отображение имени и диалога NPC
- Обновление статуса NPC

**Требования к узлу**:```
NPC (Node2D)
├── Sprite2D
├── InteractionArea (Area2D)
│   └── CollisionShape2D
├── NameLabel (Label)
└── DialogueLabel (Label)
```

**Параметры экспорта**:```gdscript
@export var npc_name: String = "Чжан Сань"
@export var npc_title: String = "Pythonинженер"
```

**Как использовать**:
1. Установите имя и должность NPC в Инспекторе.
2. Скрипт автоматически обрабатывает логику взаимодействия.

---

### 5.dialog_ui.gd (диалоговый интерфейс)
**Цель**: Управление диалоговым интерфейсом.

**Основные характеристики**:
- Показать/скрыть диалоговое окно
- Обработка ввода игрока
- Показать историю разговоров
- Общаться через API

**Требования к узлу**:```
DialogueUI (CanvasLayer)
└── Panel
    ├── NPCName (Label)
    ├── NPCTitle (Label)
    ├── DialogueText (RichTextLabel)
    ├── PlayerInput (LineEdit)
    ├── SendButton (Button)
    └── CloseButton (Button)
```

**Как использовать**:```gdscript
# Начать разговор
get_tree().call_group("dialogue_system", "start_dialogue", "Чжан Сань")
```

---

### 6. main.gd (основная сцена)
**Цель**: управлять всей игровой сценой.

**Основные характеристики**:
- Регулярно обновляйте статус NPC
- Распределить разговоры NPC по различным узлам NPC.
- Координировать различные системы.

**Требования к узлу**:```
Main (Node2D)
├── TileMapLayer (карта)
├── Player (реализация)
├── NPCs (Node2D)
│   ├── NPC_Zhang (реализация)
│   ├── NPC_Li (реализация)
│   └── NPC_Wang (реализация)
└── DialogueUI (реализация)
```

## 🔧 Как использовать эти скрипты

### Шаг 1. Настройте автозагрузку
В «Проект -> Настройки проекта -> Автозагрузка» добавьте:
- `config.gd` -> Имя: `Config`
- `api_client.gd` -> Имя: `APIClient`

### Шаг 2: Прикрепите скрипт к сцене
- `player.tscn` -> добавить `player.gd`
- `npc.tscn` -> добавить `npc.gd`
- `dialogue_ui.tscn` -> добавить `dialogue_ui.gd`
- `main.tscn` -> добавить `main.gd`

### Шаг 3. Настройте узлы
Убедитесь, что структура узлов каждой сцены соответствует требованиям сценария.

### Шаг 4: Установите параметры
Установите параметры экспорта (например, имя NPC, скорость и т. д.) в Инспекторе.

## 📊 Схема прохождения сигналов

```
Игрок нажимает клавишу E
    ↓
player.gd: interact_with_npc()
    ↓
отправить сигнал на dialogue_system Группа
    ↓
dialogue_ui.gd: start_dialogue(npc_name)
    ↓
Отображение диалогового окна, и игрок вводит сообщение.
    ↓
dialogue_ui.gd: send_message()
    ↓
api_client.gd: send_chat(npc_name, message)
    ↓
HTTPпросилFastAPIзадняя часть
    ↓
api_client.gd: _on_chat_request_completed()
    ↓
отправить сигнал: chat_response_received
    ↓
dialogue_ui.gd: _on_chat_response_received()
    ↓
Показать ответы NPC
```

## 🎯 Предложения по расширению

### Добавить нового NPC
1. Создайте экземпляр npc.tscn в main.tscn.
2. Установите имя и местоположение NPC.
3. Добавьте сопоставление в get_npc_node() в main.gd.

### Добавление новых функций
1. Добавьте конфигурацию в `config.gd`
2. Добавьте новые методы API в `api_client.gd`
3. Реализовать логику в соответствующем скрипте

### Оптимизация производительности
1. Уменьшите частоту обновления `NPC_STATUS_UPDATE_INTERVAL`.
2. Используйте пул объектов для управления элементами пользовательского интерфейса.
3. Оптимизируйте слой столкновений TileMap.

## ❓ Часто задаваемые вопросы

**В: Как изменить адрес API?**
О: Отредактируйте API_BASE_URL в config.gd.

**В: Как добавить больше NPC?**
О: Создайте экземпляр npc.tscn, установите параметры и добавьте ссылки в main.gd.

**В: Как настроить стиль диалогового окна?**
О: Отредактируйте `dialogue_ui.tscn` и измените темы Panel и Label.

**В: Как отключить журналы отладки?**
О: Установите `DEBUG_MODE = false` в `config.gd`
