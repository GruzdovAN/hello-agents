#cybertown-бэкэнд FastAPI

Серверная служба диалоговой системы AI NPC на основе платформы HelloAgents.

## 🎯 Особенности

### Основные функции
- ✅ **Диалог с одним NPC**: диалог между игроками и NPC в реальном времени, обрабатываемый независимым агентом.
- ✅ **Пакетная генерация диалогов**: генерируйте автономные диалоги всех NPC в пакетном режиме через регулярные промежутки времени, сокращая затраты на API на 66 %.
- ✅ **Управление статусом**: автоматическое обновление и кэширование статуса NPC.
- ✅ **Поддержка CORS**: поддержка экспортного междоменного доступа Godot HTML5.

###NPC-персонажи
1. **Чжан Сан** — инженер Питон (рабочая областная станция)
2. **Ли Сы** — Менеджер по продукту (конференц-зал)
3. **Ван Ву** — дизайнер пользовательского интерфейса (зона отдыха)

## 🎨 Основной дизайн

### Пакетное создание диалога
Чтобы сократить затраты на API и задержки, система использует стратегию пакетной генерации:

**Традиционный способ**:
- 3 NPC × каждые 30 секунд = 6 вызовов API в минуту.
- Ежечасно: 360 звонков

**Пакетный метод**:
- 1 пакетный вызов/30 секунд = 2 вызова API/минуту.
- Ежечасно: 120 звонков
- **Стоимость снижена на 66%!**

### Рабочий процесс```
1. Триггеры таймера (30 секунд)
   ↓
2. Слова подсказки для пакетного генератора
   ↓
3. Один вызов LLM генерирует все диалоги NPC.
   ↓
4. Разобрать ответ JSON
   ↓
5. Обновить кеш диспетчера состояний
   ↓
6. Клиент Godot регулярно получает статус
```

## 🔧 Инструкция по настройке

### config.py
```python
# Интервал обновления NPC (секунды)
NPC_UPDATE_INTERVAL = 30

# Конфигурация LLM
OPENAI_MODEL = "gpt-4o-mini"  # Рекомендуется использовать мини-версию для снижения затрат.
```

### Настройка частоты обновлений
Измените NPC_UPDATE_INTERVAL в config.py:
- Тест развития: 10 секунд
- Официальная работа: 30-60 секунд
- Режим низкой стоимости: 120 секунд.

## 🐛 Устранение неполадок

### Проблема 1. Ошибка запуска.```
❌ Инициализация LLM не удалась.
```**Решение**. Проверьте, установлена ​​ли переменная среды OPENAI_API_KEY.

### Проблема 2: беседа не отвечает```
⚠️ Будет использоваться режим разговора по умолчанию.
```**Решение**: система автоматически переходит к диалоговому окну по умолчанию, не затрагивая основные функции.

### Вопрос 3: ошибка CORS
**Решение**: проверьте конфигурацию CORS_ORIGINS в файле config.py.

## 📝 Предложения по развитию

### Добавить нового NPC
1. Добавьте конфигурацию в `NPC_ROLES` в `agents.py`.
2. Добавьте предустановленные диалоги в `preset_dialogues` файла `batch_generator.py`.
3. Перезапустите службу.

### Пользовательский стиль разговора
Измените функцию create_system_prompt в Agents.py.

### Настройка пакетной генерации подсказок
Измените функцию `_build_batch_prompt` в `batch_generator.py`.
