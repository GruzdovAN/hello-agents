# Руководство по использованию системы журнала разговоров

## 📝 Обзор

Чтобы облегчить учащимся просмотр и анализ процесса диалога с NPC, мы внедрили полную систему журналов для вывода всей информации диалога в:
- ✅ **Консоль** — Просмотр в реальном времени
- ✅ **Файл журнала** — постоянное хранилище для удобного просмотра.

---

## 🎯 Особенности

### 1. Автоматически записывать информацию о разговоре

Система журналов автоматически записывает:
- 💬 Начало/окончание разговора
- 📝 Новости игроков
- 💖 Текущий уровень благосклонности и отношений
- 🧠 Получены связанные воспоминания
- 🤖 Содержание ответа NPC
- 📊 Анализ изменения благоприятности
- 🎉 Изменения уровня отношений
- 💾 Подтверждение сохранения в памяти

### 2. Двойной выход

- **Консольный вывод** — просмотр в реальном времени для упрощения отладки.
- **Вывод файла** — Постоянное сохранение для удобства просмотра и анализа.

### 3. Сортировка по дате

Файлы журналов автоматически сортируются по дате:```
backend/logs/
├── dialogue_2025-01-15.log
├── dialogue_2025-01-16.log
└── dialogue_2025-01-17.log
```

---

## 📂 Структура файла

```
code/chapter15/backend/
├── logger.py              # Основной модуль системы регистрации
├── view_logs.py           # Инструмент просмотра журналов
├── agents.py              # ✅ Интегрированная система журналирования
└── logs/                  # Каталог файлов журнала (создается автоматически)
    └── dialogue_YYYY-MM-DD.log
```

---

## 🚀 Как использовать

### Способ 1. Запустите серверную службу (автоматическая запись)

```bash
cd code/chapter15/backend
python main.py
```

**Журнал будет автоматически записан в:**
- Консоль (отображение в реальном времени)
- `logs/dialogue_YYYY-MM-DD.log` (постоянное хранилище)

**Расположение файла журнала будет отображаться при запуске:**```
📝 Файл журнала разговоров: D:\code\...\backend\logs\dialogue_2025-01-15.log
📂 Каталог журналов: D:\code\...\backend\logs
```

---

### Способ 2: просмотр файлов журналов в режиме реального времени

**Запустить в другом окне терминала:**```bash
cd code/chapter15/backend
python view_logs.py tail
```

**Эффект:**
- Отображение содержимого журнала в реальном времени (аналогично `tail -f`)
- Новые разговоры появятся сразу
- Нажмите `Ctrl+C`, чтобы остановить просмотр.

---

### Способ 3: просмотреть полный журнал

```bash
cd code/chapter15/backend
python view_logs.py view
```

**Эффект:**
- Отображение полного содержимого журнала за сегодняшний день.
- Отображение всех записей разговоров одновременно

---

### Способ 4: вывести список всех файлов журналов

```bash
cd code/chapter15/backend
python view_logs.py list
```

**Эффект:**```
============================================================
📂 Список файлов журнала
📁 Оглавление: D:\code\...\backend\logs

1. dialogue_2025-01-15.log

## 🔧 Техническая реализация

### основные функции logger.py

```python
# Создать регистратор
dialogue_logger = logging.getLogger("dialogue")

# Обработчик файлов – сохранить в файл
file_handler = logging.FileHandler(LOG_FILE, encoding="utf-8")

# Обработчик консоли — вывод на консоль
console_handler = logging.StreamHandler()

# Добавить обработчики
dialogue_logger.addHandler(file_handler)
dialogue_logger.addHandler(console_handler)
```

### метод интеграции Agents.py

```python
from logger import (
    log_dialogue_start, log_affinity, log_memory_retrieval,
    log_generating_response, log_npc_response, log_analyzing_affinity,
    log_affinity_change, log_memory_saved, log_dialogue_end
)

def chat(self, npc_name: str, message: str, player_id: str = "player") -> str:
    # Запись разговора начинается
    log_dialogue_start(npc_name, message)
    
    # Запись благосклонности
    log_affinity(npc_name, affinity, affinity_level)
    
    # Запись восстановления памяти
    log_memory_retrieval(npc_name, len(relevant_memories), relevant_memories)
    
    # Записывайте ответы NPC
    log_npc_response(npc_name, response)
    
    # Зафиксируйте изменения в благосклонности
    log_affinity_change(affinity_result)
    
    # Конец записанного разговора

## 📋 Часто задаваемые вопросы

### В1: Где находятся файлы журналов?

**A:** Файлы журналов сохраняются в каталоге `backend/logs/` и именуются по дате:```
backend/logs/dialogue_YYYY-MM-DD.log
```

Полный путь к файлу журнала отображается при запуске серверной службы.

---

### Q2: Как просмотреть логи в режиме реального времени?

**О:** Есть два способа:

**Метод 1. Просмотр вывода консоли**```bash
cd code/chapter15/backend
python main.py
```

**Метод 2. Используйте инструмент просмотра журналов**.```bash
# в другом окне терминала
cd code/chapter15/backend
python view_logs.py tail
```

---

### В3: Файлы журналов займут много места?

**О:** Нет. Файлы журналов классифицируются по дате, по одному файлу в день. В целом:
- Примерно 0,5-1 КБ за разговор
- 100 разговоров примерно 50-100 Кб
- Дневной журнал обычно не превышает 1 МБ.

---

### В4: Могу ли я просмотреть журнал истории?

**А:** Да! Используйте следующую команду:

```bash
# Список всех файлов журналов
python view_logs.py list

# Просмотр журналов за определенную дату
python view_logs.py view
```

Или откройте файл журнала напрямую:```
backend/logs/dialogue_2025-01-15.log
```
