# Полное руководство по созданию и оценке данных AIME

В этом документе описаны полные этапы работы: от генерации данных до составления оценочного отчета.

## Подготовка

### 1. Конфигурация среды

Убедитесь, что все зависимости установлены:

```bash
# Установите и оцените системные зависимости
pip install hello-agents[evaluation]

# или установить вручную
pip install datasets huggingface_hub pandas tqdm gradio
```

### 2. Конфигурация переменных среды

Настройте в файле `.env`:

```bash
# Ключ API LLM (выберите один из двух)
DASHSCOPE_API_KEY=your_dashscope_key  # Облако Alibaba DashScope
OPENAI_API_KEY=your_openai_key        # OpenAI

# Токен HuggingFace (используется для загрузки наборов данных)
HF_TOKEN=your_hf_token
```

## Выполните шаги бега

### Шаг 1. Запустите полный процесс оценки

Это метод **операции в один клик**, который автоматически завершает генерацию, оценку и создание отчета:

```bash
cd docs/chapter12/HelloAgents
python data_generation/run_complete_evaluation.py 30 3.0
```

**Описание параметра**:
- `30` - создать 30 вопросов.
- `3.0` - 3 секунды между каждым поколением (рекомендуется 2-3 секунды)

**Описание**:
- Используйте реальные вопросы AIME 2025 в качестве ориентира для оценки.
- Источник набора данных: math-ai/aime25 (формат JSONL).

**Приблизительное время**:
- Генерация 30 вопросов: около 15-30 минут (зависит от скорости API)
- Оценка судьи LLM: около 10-15 минут.
- Оценка процента побед: около 5-10 минут.
- **Всего**: примерно 30–55 минут.

**Выходной файл**:```
data_generation/
├── generated_data/
│   └── aime_generated_YYYYMMDD_HHMMSS.json  # сгенерированные вопросы
└── evaluation_results/
    └── YYYYMMDD_HHMMSS/
        ├── llm_judge/
        │   ├── llm_judge_result_YYYYMMDD_HHMMSS.jsonl
        │   └── llm_judge_report_YYYYMMDD_HHMMSS.md
        ├── win_rate/
        │   ├── win_rate_result_YYYYMMDD_HHMMSS.jsonl
        │   └── win_rate_report_YYYYMMDD_HHMMSS.md
        └── comprehensive_report.md  # интегрированная отчетность
```

### Шаг 2. Просмотрите отчет об оценке

#### 2.1 Просмотр подробного отчета

```bash
# Найдите последний каталог результатов оценивания
cd data_generation/evaluation_results
ls -lt  # Посмотреть последний каталог

# Посмотреть подробный отчет
cat YYYYMMDD_HHMMSS/comprehensive_report.md
```

**Комплексный отчет содержит**:
- Основная информация (время генерации, количество вопросов и т.д.)
- Статистика формирования данных (распределение тем, анализ ответов)
- Результаты оценки судьи LLM (общая оценка, оценка по каждому параметру)
- Результаты оценки винрейта (статистика винрейта, сравнительный анализ)
- Исчерпывающие выводы и предложения по улучшению.

#### 2.2 Посмотреть подробный отчет

**Подробный отчет судьи LLM**:```bash
cat YYYYMMDD_HHMMSS/llm_judge/llm_judge_report_YYYYMMDD_HHMMSS.md
```

**Подробный отчет о проценте побед**:```bash
cat YYYYMMDD_HHMMSS/win_rate/win_rate_report_YYYYMMDD_HHMMSS.md
```

### Шаг 3. Проверка вручную (необязательно)

Если требуется ручная проверка, запустите:

```bash
python data_generation/human_verification_ui.py data_generation/generated_data/aime_generated_YYYYMMDD_HHMMSS.json
```

**Этапы работы**:
1. Браузер автоматически открывает http://127.0.0.1:7860.
2. Прочитайте вопросы, ответы и решения.
3. Оценка по 4 измерениям (1-5 баллов)
4. Выберите статус проверки (одобрено/отклонено/нужна_переработка)
5. Добавьте комментарий (необязательно)
6. Нажмите «Отправить подтверждение».
7. Проверьте следующий вопрос

**Сохранить результаты проверки**:```
data_generation/generated_data/aime_generated_YYYYMMDD_HHMMSS_verifications.json
```

## ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### 1. Ограничение скорости API

**вопрос**:```
INFO:openai._base_client:Retrying request to /chat/completions in 0.451826 seconds
```

**Решение**:
— Увеличьте время задержки: `python data_generation/run_complete_evaluation.py 30 5.0`
- Используйте восстановление контрольной точки: повторное выполнение той же команды после прерывания автоматически возобновляется.

### 2. HuggingFace загружается медленно

**Проблема**: Загрузка набора данных AIME происходит медленно.

**решать**:```bash
# Использовать зеркальный источник
export HF_ENDPOINT=https://hf-mirror.com

# Или используйте локальный путь после загрузки вручную.
```

### 3. Создавайте повторяющиеся вопросы

**Проблема**: сгенерированные вопросы дублируются.

**Решение**:
- Более 900 реальных вопросов были использованы в качестве эталонных образцов.
- Случайным образом выбирайте разные ссылки для каждой сборки.
- В слове подсказки подчеркивается «генерировать совершенно разные вопросы».

### 4. Оценка не удалась

**Проблема**: не удалось оценить оценку судьи LLM или процента побед.

**Решение**:
- Проверьте правильность ключа API.
- Проверьте, существует ли сгенерированный файл данных.
- Проверьте правильность формата файла данных.

## Стандарт качества

### Отличные стандарты
- Средний балл судьи LLM ≥ 4,5/5,0
- Процент побед ≥ 48% (почти 50%)
- Процент сдачи ≥ 90%
- Процент прохождения ручной проверки ≥ 95%

### Хорошие стандарты
- Средний балл судьи LLM ≥ 4,0/5,0
- Вероятность выигрыша ≥ 45%
- Процент сдачи ≥ 80%
- Процент прохождения ручной проверки ≥ 90%

### Требует улучшения
- Средний балл судьи LLM < 4,0/5,0
- Процент побед <45%
- Процент сдачи < 80%
- Процент прохождения ручной проверки <90 %

## Следующий шаг

По результатам оценки:

1. **Если качество отличное**:
   - Можно использовать сгенерированные данные
   – Рассмотрите возможность создания большего количества данных.
   - Сохраняйте отчет об оценке как доказательство качества.

2. **Если качество хорошее**:
   - Выполните ручную проверку.
   - Фильтровать высококачественные данные
   -Настройте сгенерированные слова-подсказки

3. **Если необходимы улучшения**:
   - Анализировать общие проблемы в вопросах с низкими оценками.
   -Настройте сгенерированные слова-подсказки
   - Восстановить и оценить
