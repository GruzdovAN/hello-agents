## 🚀 Быстрый старт

### Подготовка среды

1. **Установите платформу HelloAgents**:```bash
   pip install hello-agents[evaluation]==0.2.3
   ```

2. **Установите переменные среды**:```bash
   # Ключ API OpenAI (для GPT-4o)
   export OPENAI_API_KEY="your_openai_api_key"
   
   # Токен HuggingFace (для набора данных GAIA)
   export HF_TOKEN="your_huggingface_token"
   ```

3. **Загрузить набор данных BFCL** (необязательно, в первый раз он будет загружен автоматически):```bash
   cd ../HelloAgents
   git clone https://github.com/ShishirPatil/gorilla.git temp_gorilla
   ```

## 💡 Часто задаваемые вопросы

### В1: При запуске примера появляется сообщение, что модуль не найден?

О: Убедитесь, что платформа HelloAgents установлена:```bash
cd ../HelloAgents
pip install -e .
```

### Вопрос 2: Оценка BFCL сообщает, что набор данных не найден?

О: Набор данных будет автоматически загружен во время первого запуска. Пожалуйста, убедитесь, что сетевое соединение нормальное. Если загрузка не удалась, вы можете загрузить ее вручную:```bash
cd ../HelloAgents
git clone https://github.com/ShishirPatil/gorilla.git temp_gorilla
```

### В3: Оценка GAIA сообщает, что нет прав доступа?

О: GAIA — это набор данных с ограниченным доступом, и вам необходимо сначала подать заявку на разрешение доступа:
1. Посетите https://huggingface.co/datasets/gaia-benchmark/GAIA.
2. Нажмите «Запросить доступ».
3. Ожидание одобрения
4. Установите переменную среды HF_TOKEN.

### В4: Скорость оценки слишком низкая?

О: Количество образцов может быть уменьшено:```python
# Оценка BFCL
results = bfcl_tool.run(agent, category="simple_python", max_samples=5)

# оценка GAIA
results = gaia_tool.run(agent, level=1, max_samples=2)

# Оценка генерации данных
python 07_data_generation_complete_flow.py 10 3.0  # Создайте только 10 вопросов
```

### Q5: Как оценить стоимость оценки?

О: Стоимость оценки в основном связана с вызовами LLM API:

**Оценка BFCL**:
- Около 1 вызова API на образец
- Стоимость составляет около 0,01-0,02 юаня/образец.
- Полная оценка (400 образцов) стоит около 4-8 юаней.

**Оценка GAIA**:
- Около 1-5 вызовов API на образец (в зависимости от сложности задачи)
- Стоимость составляет около 0,05-0,20 юаней/образец.
- Полная оценка (466 образцов) составляет около 23-93 юаней.

**Оценка формирования данных**:
- Генерация: около 0,05 юаня/вопрос
- Судья LLM: около 0,02 юаня/вопрос.
- Процент побед: около 0,02 юаня за сравнение.
- Создайте 30 вопросов примерно за 2-3 юаня.
