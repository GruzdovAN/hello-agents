# Случай сотрудничества команды разработчиков программного обеспечения AutoGen

В этом каталоге содержится полный практический пример платформы AutoGen из главы 6, показывающий, как использовать AutoGen для создания многоагентной совместной группы разработчиков программного обеспечения.

## 📁 Описание файла

- `autogen_software_team.py` — основной код дела (на основе клиента OpenAI)
- `llm_client.py` — реализация клиента HelloAgentsLLM.
- `requirements.txt` — список зависимых пакетов
- `output.py` — пример приложения цены на биткойны, созданный в результате совместной работы команды.
- `README.md` - эта документация

## 🚀 Особенности корпуса

- **Многоагентное сотрудничество**: демонстрирует полный процесс совместной работы менеджеров по продуктам, инженеров, рецензентов кода и пользовательских агентов.
- **Реальный сценарий разработки**: полный жизненный цикл разработки программного обеспечения от анализа требований до реализации кода.
- **Автоматизированный процесс**: автоматическая передача задач между агентами без ручного вмешательства.
- **Генерация и проверка кода**: автоматическое создание работоспособного кода и проведение проверки качества.

## 🛠️Подготовка среды

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Настройте переменные среды

Создайте файл `.env` и настройте следующие параметры:

```bash
# Конфигурация LLM
LLM_API_KEY=your-api-key-here
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL_ID=gpt-4
```

### 3. Среда проверки

Убедитесь, что LLM API можно вызвать нормально:

```python
import os
from dotenv import load_dotenv
load_dotenv()

print(f"API Key: {os.getenv('LLM_API_KEY')[:10]}...")
print(f"Base URL: {os.getenv('LLM_BASE_URL')}")
print(f"Model: {os.getenv('LLM_MODEL_ID')}")
```

## 🎯 Текущее дело

### Начало совместной работы группы разработчиков программного обеспечения

```bash
python autogen_software_team.py
```

### Ожидаемый выходной процесс

1. **🔧 Инициализация клиента модели**
2. **👥Создание команды агентов**
3. **🚀Началось командное сотрудничество**
4. **💬 Процесс диалога с агентом**:
   - ProductManager: анализ спроса и технологическое планирование.
   - Инженер: реализация кода
   - CodeReviewer: обзор кода и предложения по оптимизации.
   - UserProxy: пользовательское тестирование и отзывы.
5. **✔Сотрудничество завершено**

## 👥 Описание роли агента

### 🎯 ProductManager (Менеджер по продукту)
- **Обязанности**: Анализ требований, техническое планирование, оценка рисков.
- **Результат**: функциональное разделение модулей, предложения по техническому отбору, критерии приемки.
- **Особенности**: внимание к пользовательскому опыту и реализуемости продукта.

### 💻 Инженер (Инженер-программист)
- **Обязанности**: Реализация кода, разработка технических решений.
- **Выход**: полный работоспособный код.
- **Особенности**: Знание Python, Streamlit, интеграция API.

### 🔍 CodeReviewer (проверщик кода)
- **Обязанности**: Проверка качества кода, проверка безопасности.
- **Результат**: отчет о проверке кода, предложения по оптимизации.
- **Особенности**: внимание к спецификациям кода, производительности и безопасности.

### 👤 UserProxy (пользовательский агент)
- **Обязанности**: представление потребностей пользователей, проведение тестирования, предоставление отзывов.
- **Результаты**: результаты испытаний, отзывы пользователей.
- **Функция**: проверка функциональности с точки зрения пользователя.

## 🔧 Пользовательская конфигурация

### Изменить роль агента

Поведение агента можно настроить, изменив `system_message`:

```python
def create_product_manager(model_client):
    system_message = """
    Вы опытный менеджер по продукту.
    # Настройте описание своей роли здесь
    """
    return AssistantAgent(
        name="ProductManager",
        model_client=model_client,
        system_message=system_message,
    )
```

### Настройте процесс сотрудничества

Список участников и условия прекращения могут быть изменены:

```python
team_chat = RoundRobinGroupChat(
    participants=[
        product_manager,
        engineer, 
        code_reviewer,
        user_proxy
    ],
    termination_condition=TextMentionTermination("TERMINATE"),
    max_turns=20,  # Отрегулируйте максимальное количество раундов
)
```

## 🐛 Часто задаваемые вопросы

### Вопрос: Агент не начал разговор?
О: Проверьте следующие пункты:
- Убедитесь, что ключ API настроен правильно.
- Проверьте сетевое соединение
- Убедитесь, что название модели правильное.

### В: Процесс сотрудничества прерван?
О: Возможные причины:
- Ограничения вызовов API
- Тайм-аут сети
- Модель реагирует ненормально

### Вопрос: Сгенерированный код невозможно запустить?
А: Предложение:
- Проверьте, полностью ли установлены зависимые пакеты.
- Проверьте, доступен ли интерфейс API.
- Просмотр журналов ошибок для отладки.
