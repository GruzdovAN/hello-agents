#AgentScope Дело об убийстве оборотня «Троецарствие»

В этом каталоге содержится полный практический пример платформы AgentScope из главы 6, показывающий, как использовать AgentScope для создания многоагентной онлайн-игры, включающей элементы классической китайской культуры.

## 📁 Описание файла

- `main_cn.py` — основная игровая логика и контроллер
- `prompt_cn.py` — управление словами китайской подсказки.
- `game_roles.py` — определение и настройка игровой роли.
- `structured_output_cn.py` — определение модели структурированного вывода.
- `utils_cn.py` — функции игрового инструмента и вспомогательные методы.
- `README.md` - эта документация

## 🎮 Особенности корпуса

- **Архитектура, управляемая сообщениями**: демонстрирует основной механизм обмена сообщениями AgentScope.
- **Параллельное сотрудничество**: демонстрирует одновременное взаимодействие нескольких онлайн-агентов в режиме реального времени.
- **Ролевая игра**: у каждого агента двойная личность (игровой персонаж + персонажи Трех Королевств).
- **Структурированный вывод**: ограничение поведения агента с помощью модели Pydantic.
- **Механизм отказоустойчивости**: аномалии в одном агенте не влияют на общий игровой процесс.

## 🛠️Подготовка среды

### 1. Установите зависимости

```bash

```

### 2. Настройте переменные среды

Установите ключ API Alibaba Cloud DashScope:

```bash
# Linux/Mac
export DASHSCOPE_API_KEY="your-api-key-here"

# Windows PowerShell
$env:DASHSCOPE_API_KEY="your-api-key-here"

# Windows CMD
set DASHSCOPE_API_KEY=your-api-key-here
```

Получите ключ API: https://dashscope.console.aliyun.com/apiKey.

### 3. Запустите игру

```bash
python main_cn.py
```

## 🏗️ Архитектурный дизайн

### Многоуровневая архитектура```
уровень управления игрой (ThreeKingdomsWerewolfGame)
    ├── Управление состоянием игры
    ├── управление процессом
    └── Определение победы или поражения

Уровень взаимодействия агентов (MsgHub)
    ├── маршрутизация сообщений
    ├── Параллельная обработка
    └── Государственная синхронизация

слой ролевого моделирования (DialogAgent)
    ├── подсказки персонажей
    ├── Структурированный вывод
    └── поведенческие ограничения
```

### Основные компоненты

**1. Центр сообщений (MsgHub)**```python
async with MsgHub(
    participants=self.werewolves,
    enable_auto_broadcast=True
) as hub:
    # Ночь оборотня. Обсуждение.
    for wolf in self.werewolves:
        await wolf(structured_model=DiscussionModelCN)
```

**2. Структурированный вывод**```python
class VoteModelCN(BaseModel):
    voice: str = Field(description="Проголосовать за имя целевого игрока")
    причина: str = Field(description="Причина голосования")
    уверенность: int = Поле(ge=1, le=10, описание="Уровень уверенности")
```

**3. Параллельный конвейер**```python
vote_msgs = await fanout_pipeline(
    self.alive_players,
    msg=vote_announcement,
    structured_model=get_vote_model_cn(self.alive_players),
    enable_gather=False,

```

## 🎯 Ход игры

### Ночная фаза
1. **Обсуждение оборотней**: Оборотни договариваются об убийстве цели через MsgHub.
2. **Проверка пророка**: Оракул выбирает объект проверки.
3. **Действие ведьмы**: Ведьма решает, использовать ли противоядие/яд.

### Фаза дня
1. **Объявление о смерти**: Объявление об игроках, умерших ночью.
2. **Бесплатное обсуждение**: в обсуждении участвуют все выжившие игроки.
3. **Голосование за удаление**: проголосуйте за объекты, которые необходимо устранить.
4. **Навыки охотника**: убитые охотники могут стрелять.

## 🐛 Часто задаваемые вопросы

### В: Невозможно запустить игру?
О: Проверьте следующие пункты:
- Убедитесь, что переменная среды DASHSCOPE_API_KEY установлена.
- Проверьте, действителен ли ключ API.
- Проверьте, нормально ли сетевое соединение

### Вопрос: Неправильный формат вывода агента?
О: Возможные причины:
-Ограничения в возможностях понимания модели.
- Дизайн подсказки недостаточно ясен.
- Структурированные выходные ограничения слишком сложны.

### В: Игровой процесс завис?
А: Предложение:
- Проверьте сообщения MsgHub.
- Проверка статуса выполнения параллельных конвейеров.
- Просмотр журнала ошибок консоли.
