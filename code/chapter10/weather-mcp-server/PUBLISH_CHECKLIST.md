# Опубликовать контрольный список

Перед отправкой в ​​Smithery убедитесь, что вы выполнили все следующие пункты:

## 📋 Проверка файлов

- [ ] README.md полный и понятный
- [ ] Файл ЛИЦЕНЗИИ существует.
- [ ] Dockerfile настроен правильно (рекомендуется)
- [ ] pyproject.toml настроен правильно (обязательно)
- [ ] require.txt содержит все зависимости
- [ ] smithery.yaml настроен правильно
- [ ] server.py может работать нормально

## 🧪 Функциональное тестирование

- [ ] Сервер может запуститься нормально
- [ ] Все инструменты можно вызывать обычным образом
- [ ] Улучшена обработка ошибок
- [ ] Формат возвращаемого результата правильный

## 📝 Проверка документации

- [ ] Четкие инструкции по установке
- [ ] Полный пример использования
- [ ] Подробности документации API
- [ ] Полный список поддерживаемых функций.

## 🔧 Проверка конфигурации

- [] имя и версия в pyproject.toml верны.
- [ ] уникальное имя в smithery.yaml
- [] Поддерживайте согласованность версий pyproject.toml и smithery.yaml.
- [ ] версия соответствует семантическому версионированию
- [ ] Полный список инструментов
- [ ] URL домашней страницы правильный

## 🚀 Подготовка GitHub

- [ ] Код отправлен на GitHub.
- [ ] создан тег v1.0.0
- [ ] Создан выпуск
- [ ] Репозиторий является общедоступным.

## ✅ Заключительная проверка

- [ ] Пройден местный тест
- [ ] В документе нет орфографических ошибок.
- [ ] Все ссылки доступны
- [ ] готово для отправки в Кузницу

## Отправить шаги

1. Посетите https://smithery.ai/.
2. Войдите с помощью GitHub.
3. Нажмите «Отправить сервер».
4. Введите URL-адрес склада.
5. Подтвердите информацию и отправьте
6. Ожидание рассмотрения (1-3 дня)

- [ ] Тестовая установка и использование
- [ ] Поделиться с сообществом
