## О проекте

&emsp;&emsp;Если 2024-й был годом «битвы сотен моделей», то 2025-й без сомнения открыл «Год агентов». Hello-Agents — систематический курс сообщества Datawhale по построению **AI-native агентов** с нуля: от принципов и классических парадигм до мультиагентных приложений.

> Локальная русская редакция ядра курса и Co-creation-projects.
