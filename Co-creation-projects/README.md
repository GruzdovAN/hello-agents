## 🚀 Как добавить свой проект

### 1. Именование

Формат папки: `{GitHub-логин}-{НазваниеПроекта}`

Примеры:
- `jjyaoao-CodeReviewAgent`
- `zhangsan-StudyBuddy`
- `lisi-DataAnalyst`

### 2. Структура

Минимум в каждом проекте:

```
ваш-логин-название/
├── README.md              # описание (обязательно)
├── requirements.txt       # зависимости Python (обязательно)
├── main.ipynb            # основной Jupyter Notebook (обязательно)
└── ...                   # остальное по желанию
```

### 3. Требования к README

В README должны быть:

- краткое описание проекта
- ключевые функции
- стек технологий
- быстрый старт (установка, настройка, запуск)
- пример использования
- информация об авторе

Шаблон: [EXAMPLE-ProjectTemplate](./EXAMPLE-ProjectTemplate/README.md)

### 4. Как отправить

1. Сделайте Fork репозитория Hello-Agents
2. Создайте папку проекта в `Co-creation-projects`
3. Разработайте проект и документацию
4. Откройте Pull Request

Подробнее: [Глава 16. Дипломный проект](../docs/chapter16/Chapter16-Graduation-Project.md)
