# Агент-колумнист (Column Writer Agent)

Интеллектуальная система написания колонок на базе фреймворка [HelloAgents](https://github.com/helloagents/hello-agents): несколько агентов и паттернов проектирования автоматически выполняют планирование, написание, ревью и оптимизацию колонки.
![Скриншот выполнения](./assets/agent_run.jpg)

## ▸ О проекте

Агент имитирует профессиональную творческую команду:
- **эксперт по планированию**: верхнеуровневый дизайн и контент-план;
- **эксперт по написанию**: текст и вызов инструментов;
- **эксперт по ревью**: контроль качества и обратная связь.

Поддерживается рекурсивная древовидная генерация оглавления колонки — можно создавать длинные технические колонки со строгой структурой и подробным содержанием.

## ▸ Основные возможности

1.  **Интеллектуальное планирование и декомпозиция**:
    *   паттерн Plan-and-Solve автоматически разбивает широкую тему (например, «асинхронное программирование в Python») на полный план с подтемами и главами;
    *   поддержка многоуровневой рекурсивной раскладки для глубокого контента.

2.  **Многорежимное написание**:
    *   **ReAct (Reasoning + Acting)**: сочетание рассуждения и действия; при написании агент активно вызывает поиск для актуальной информации;
    *   **Reflection**: механизм саморефлексии (Self-Reflection) — после черновика автоматическое ревью и улучшение.

3.  **Усиление через веб-поиск**:
    *   интеграция Tavily/SerpApi для актуальности и точности;
    *   интеграция GitHub MCP — чтение кода open source в качестве примеров.

4.  **Замкнутый контроль качества**:
    *   встроенная система оценки по нескольким измерениям (точность, логика, читаемость);
    *   при низком балле автоматически запускается доработка до достижения порога.

5.  **Умное кэширование и отказоустойчивость**:
    *   кэш результатов планирования, чтобы не генерировать повторно;
    *   восстановление при сбоях вызова агента с понижением режима, чтобы задача завершилась.

## ▸ Технологический стек

*   **Основной фреймворк**: [HelloAgents](https://github.com/helloagents/hello-agents)
*   **Паттерны агентов**: Plan-and-Solve, ReAct, Reflection
*   **Инструменты**:
    *   MCP (Model Context Protocol)
    *   Tavily / SerpApi (поиск)
    *   GitHub API
*   **Среда выполнения**: Python 3.10+

## ▸ Базовый workflow

Многоэтапный рекурсивный процесс:

1.  **Планирование (Planning)**
    *   пользователь вводит тему колонки;
    *   **Planner Agent** (`PlanAndSolveAgent`) анализирует тему, декомпозирует задачу, формирует `ColumnPlan` (заголовок, введение, целевая аудитория, список подтем).

2.  **Написание (Writing — Recursive)**
    *   Orchestrator обходит подтемы и запускает задачи написания;
    *   **Writer Agent** (`ReActAgent` или `ReflectionAgent`) генерирует контент;
    *   **рекурсивное раскрытие**:
        *   **Level 1 (Topic)**: введение и обзор подтемы;
        *   **Level 2 (Section)**: разделы с углублённым изложением;
        *   **Level 3 (Detail)**: кейсы, код, детали.
    *   по `MAX_DEPTH` решается, продолжать ли раскрытие.

3.  **Вызов инструментов (Tool Use)**
    *   Writer Agent может вызывать:
        *   `web_search`: актуальные данные и статистика;
        *   `search_code_examples`: примеры кода;
        *   `verify_facts`: проверка фактов;
        *   `github` (опционально): репозитории и код проектов.

4.  **Ревью и доработка (Review & Refine)**
    *   **ReAct + независимое ревью**: после генерации `ReviewerAgent` оценивает по измерениям (качество, структура, язык, формат). Ниже порога (по умолчанию 75) — `RevisionAgent` правит по замечаниям, цикл до прохождения или лимита итераций.
    *   **Reflection**: `ReflectionAgent` — черновик, саморефлексия и оптимизация за один проход.

5.  **Сборка и экспорт (Assembly & Export)**
    *   «разворачивание» дерева контента (Content Tree);
    *   полная статья в Markdown;
    *   отчёт `REPORT.md` (объём, время, оценки качества).

## ▸ Паттерны агентов (Agent Patterns)

### 1. Plan-and-Solve (планирование и решение)
*   **Применение**: `PlannerAgent`
*   **Принцип**: сложная задача → список шагов (Plan) → пошаговое выполнение (Solve).
*   **Плюс**: макро-планирование и длинные цепочки рассуждений без хаоса одношаговой генерации.

### 2. ReAct (рассуждение + действие)
*   **Применение**: `WriterAgent`
*   **Принцип**: цикл **Reasoning (мышление)** → **Acting (действие/инструмент)** → **Observation (наблюдение)**.
*   **Плюс**: взаимодействие с внешним миром (поиск, БД), а не только обучающие данные — актуальность и точность.

### 3. Reflection (рефлексия)
*   **Применение**: `ReflectionWriterAgent`
*   **Принцип**: генерация → самооценка (Critic) → улучшение (Refine).
*   **Плюс**: выше качество текста, как у автора, который перечитывает и правит.

### 4. Independent Review (независимое ревью)
*   **Применение**: `ReviewerAgent` + `RevisionAgent`
*   **Принцип**: 
    - `ReviewerAgent`: оценка по измерениям (качество 40, структура 30, язык 20, формат 10), детальные рекомендации;
    - `RevisionAgent`: точечные правки с сохранением сильных сторон.
*   **Плюс**: разделение ролей, единые критерии, история ревью, несколько раундов до порога.

## ▸ Модели и инструменты (Models & Tools)

### Поддержка моделей
Через `config.py` — разные LLM backend:
- **другие совместимые модели**: любой API в формате OpenAI

### Инструменты модели
1.  **SearchTool (веб-поиск)**
    *   backend: Tavily (рекомендуется), SerpApi, DuckDuckGo и др.;
    *   актуальная информация, снижение галлюцинаций и устаревания знаний.
2.  **MCPTool (Model Context Protocol)**
    *   GitHub MCP Server;
    *   поиск репозиториев, просмотр файлов, анализ структуры кода для технических колонок.

## ▸ Оптимизации (Features)

### 1. Умное кэширование (Smart Caching)
*   **кэш Planner**: `CachedExecutor` кэширует шаги планирования; при той же теме — загрузка из кэша, экономия токенов и времени.
*   **файловый кэш**: `ColumnPlan` в локальной директории `.cache`.

![Механизм кэширования](./assets/feature_cache.jpg)

### 2. Разбор вывода модели (Robust Parser)
*   усиленный JSON-парсер для нестандартного вывода LLM (Markdown-блоки, комментарии, незакрытые скобки);
*   извлечение из `history` при ошибке формата, чтобы не обрывать весь pipeline.

### 3. Восстановление после ошибок (Error Recovery)
*   при исчерпании шагов или сбое `ReActAgent` — откат к `SimpleAgent` с `history_summary` для попытки завершить задачу.

![Устойчивый разбор](./assets/feature_robust.jpg)

## ▸ Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Переменные окружения
Скопируйте `env.example` в `.env`:
```env
# LLM
OPENAI_API_KEY=your_key
OPENAI_BASE_URL=...

# Поиск (опционально, рекомендуется)
TAVILY_API_KEY=tvly-... 
# или
SERPAPI_API_KEY=...

# GitHub MCP (опционально)
GITHUB_PERSONAL_ACCESS_TOKEN=...
```

### 3. Запуск
```bash
# Интерактивный режим
python main.py

# Командная строка
python main.py "Асинхронное программирование в Python"
```

После выполнения — каталог `output_YYYYMMDD_HHMMSS`.
