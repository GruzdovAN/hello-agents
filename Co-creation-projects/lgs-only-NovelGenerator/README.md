# NovelGenerator — интеллектуальный помощник для написания романов

> Интеллектуальная система вспомогательного литературного творчества на базе фреймворка HelloAgents: от идеи до готового текста.

## 📝 О проекте

**NovelGenerator** использует возможности больших языковых моделей (LLM), чтобы дать авторам романов интеллектуальные инструменты. Это не простой генератор текста, а партнёр по творчеству, который понимает структуру сюжета, сохраняет связность и опирается на контекстную память.

Проект решает ключевые проблемы написания длинных романов:
- **Сложность построения плана**: от размытой идеи до структурированного плана — с помощью ИИ.
- **Связность сюжета**: при генерации следующих глав автоматически учитываются предыдущие события и краткие пересказы.
- **Низкая скорость**: поддержка пакетной генерации глав для быстрого продвижения по сюжету.

## ✨ Основные возможности

- [x] **Интеллектуальная генерация плана**: по одной фразе-идее, заголовку и тегам формируется подробный план с миром, персонажами и разбивкой по томам.
- [x] **Генерация глав с учётом контекста**: новые главы строятся на плане и предыдущих главах; автоматически подтягиваются краткие пересказы нескольких прошлых глав и текст предыдущей главы.
- [x] **Непрерывное написание нескольких глав**: можно сгенерировать сразу несколько глав — ИИ поддерживает непрерывность сюжета.
- [x] **Система управления контентом**:
    - автоматическое сохранение плана и глав в локальные файлы (Markdown);
    - web-интерфейс и API для чтения, обновления и удаления материалов.
- [x] **Механизм творческой памяти**: автоматическое извлечение и хранение кратких пересказов глав и прогнозов для последующего написания.

## 🛠️ Технологический стек

- **Основной фреймворк**: HelloAgents — оркестрация агентов и вызов инструментов; используется SimpleAgent.
- **Web-фреймворк**: FastAPI — высокопроизводительный RESTful API.
- **Модели данных**: Pydantic — валидация и описание структур.
- **Хранение**: локальная файловая система (Markdown + JSON) — удобный просмотр и правка результатов.
- **LLM**: модели с совместимым OpenAI API (DeepSeek, Qwen и др., настройка через `.env`).

## 🚀 Быстрый старт

### Требования

- Python 3.10+

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка окружения

1. Создайте файл `.env` в корне проекта.
2. Укажите параметры LLM (см. документацию HelloAgents или вашу модель):

```
# Пример .env
LLM_PROVIDER=ollama # или openai, qwen и т.д.
LLM_MODEL_ID=qwen2.5-72b-instruct
API_KEY=your_api_key
BASE_URL=http://localhost:11434/v1 # при локальном Ollama
LLM_TIMEOUT=60
HOST=127.0.0.1
PORT=8000
```

### Запуск

#### Способ 1: API-сервис (рекомендуется)

Запуск backend для работы с frontend.

```bash
python src/app.py
# или
uvicorn src.app:app --reload
```

После запуска документация API: `http://127.0.0.1:8000/docs`


#### Способ 2: тестовый скрипт

Для проверки генерации в командной строке запустите `main.py`:

```bash
python main.py
```

## 📖 Руководство

1. **Запустите сервис** по инструкции выше.
2. **Frontend**: откройте `frontend/index.html` в браузере или раздайте через простой HTTP-сервер.
3. **Процесс работы**:
    - **Создание проекта**: введите название романа и ID.
    - **Генерация плана**: введите основную идею (например, «история о программисте-ИИ, попавшем в мир кода») и нажмите генерацию плана.
    - **Генерация глав**: после подтверждения плана перейдите к главам, при необходимости укажите краткий замысел первой главы и запустите генерацию.
    - **Просмотр и правка**: главы отображаются в списке; их можно читать и вручную сохранять после редактирования.

## 🎯 Сильные стороны

- **Согласованность длинного текста**: умное управление контекстом и памятью снижает логические сбои при длинной генерации.
- **Структурированный workflow**: путь автора (идея → план → главы), а не слепая генерация.
- **Полный контроль над данными**: весь контент в локальных Markdown-файлах — безопасно и удобно для доработки.
- **WYSIWYG**: наглядный web-интерфейс, предпросмотр в реальном времени и ручная корректировка.
