# MindEchoAgent · Эхо настроения

🧠🎵 MindEchoAgent — агент музыкальных рекомендаций по эмоциям: ИИ чувствует настроение, музыка согревает.
> Сейчас это агент рекомендаций музыки по настроению на фреймворке hello-agents.

## ✨ Особенности
- 🎧 Эмоции, а не только теги: глубокое распознавание настроения вместо простого сопоставления меток
- 🧠 Архитектура Agent + Tool: Hello-Agents, модульность и расширяемость
- 🧪 Полная симуляция, стабильность: встроенные качественные тестовые данные, все функции без API-ключа
- 🎛 Gradio для быстрой демо: веб-интерфейс из коробки
- 🔄 Память (в разработке): краткая память настроения, анализ паттернов
- 📱 Несколько платформ (планируется): мобильный веб, позже — умный дом

## 🔧 Стек
- Ядро: hello-agents >= 0.2.7
- Веб: gradio >= 4.0
- Python 3.10+
- Данные: json, datetime, typing
- Окружение: python-dotenv

## Запуск
```bash
# 1. Клонировать репозиторий
git clone https://github.com/pamdla/MindEchoAgent.git
cd MindEchoAgent

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
python main.py
```

## ⭐ Основной функционал

1. Распознавание эмоций и отклик

- Состояния диалога: начальное, распознавание эмоции, поддержка, рекомендация музыки, рефлексия, эскалация — 6 состояний
- Многомерное определение: радость, грусть, расслабление, концентрация, стресс, возбуждение
- Контекст сцены: работа, спорт, учёба, перед сном и т.д.
- Естественный язык: «сегодня устал», «настроение отличное»

2. Умные музыкальные рекомендации (в разработке)

- Плейлисты под настроение и сцену
- Движок симуляции: встроенные треки, разные стили и сцены
- Расчёт длительности прослушивания

3. Система эмоциональной поддержки

- Два режима: заготовленные ответы + генерация LLM
- Эмпатичный тон с уместными emoji
- Практические советы по регуляции эмоций

4. Анализ памяти настроения

- История каждого взаимодействия
- Тренды и распределение по времени
- Персональные выводы по истории

## 🏠 Веб-интерфейс

После запуска:

- Откройте в браузере http://localhost:7860
- Опишите настроение, например: «Большой стресс на работе, хочу расслабляющую музыку»
- В ответе:
> Результат распознавания эмоции
> Персональные рекомендации музыки
> Текст поддержки
> Отчёт по настроению
