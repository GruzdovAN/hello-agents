## 📝 О проекте

**HelloAgents Code Agent CLI** — умный помощник по коду на фреймворке HelloAgents, с опытом как у Claude Code/Codex: безопасная работа с локальным репозиторием.

### Ключевые преимущества

- **🎯 Точный поиск**: исследование по необходимости, сначала доказательства — потом вывод, без полного сканирования
- **🛡️ Безопасность**: правки патчами + атомарная запись + авто-бэкап, рискованные изменения — с подтверждением
- **🧠 ReAct**: многошаговое рассуждение и действия
- **📊 Задачи**: встроенный Todo, визуальный прогресс шагов
- **🔧 Инструменты**: терминал, контекст, заметки

## ✨ Ключевые возможности

### 1. Движок рассуждений

- **ReAct Agent**: рассуждение (Reasoning) + действие (Acting), сложные многошаговые задачи
- **Трекинг шагов**: Todo Board — pending → in_progress → completed

### 2. Безопасные патчи

```
*** Begin Patch
Update File: src/example.py
```python
# обновлённый код
```
*** End Patch
```

- ✅ Стандартный формат патча
- ✅ Атомарные операции с файлами
- ✅ Авто-бэкап (суффикс `.backup`)
- ✅ Белый список типов файлов
- ✅ Подтверждение человеком

### 3. Многоисточниковый контекст

**Конвейер GSSC** (Gather-Select-Structure-Compress):

```
Запрос → сбор → отбор по релевантности → структура → сжатие токенов → ответ
```

### 4. Экосистема инструментов

| Инструмент | Описание | Назначение |
|---------|---------|---------|
| **Terminal Tool** | Безопасный терминал (белый список) | Обзор файлов, поиск, текст |
| **Context Fetch Tool** | Контекст по запросу | Чтение файлов/каталогов |
| **Note Tool** | CRUD заметок | Решения, важные факты |
| **Todo Tool** | Управление задачами | Многошаговые задачи |
| **Plan Tool** | Планирование | Декомпозиция сложных задач |
| **Memory Tool** | Память | Долгосрочное хранение |

### Модули

#### 1. Слой Agents
- **ReActAgent**: основной цикл «мысль → действие → наблюдение»
- **PlanSolveAgent**: планирование и декомпозиция
- **ReflectionAgent**: самоанализ и улучшение
- **SimpleAgent**: базовый диалоговый агент (Agent)

#### 2. Core
- **HelloAgentsLLM**: единый LLM API (OpenAI/DeepSeek/Qwen и др.)
- **Message**: сообщения и сериализация
- **Config**: конфигурация
- **Exceptions**: иерархия исключений

#### 3. Context
- **ContextBuilder**: реализация GSSC
- **ContextConfig**: настройки контекста
- **ContextPacket**: пакеты информации

#### 4. Memory
- **MemoryManager**: единый интерфейс памяти
- **Types**: WorkingMemory, EpisodicMemory, SemanticMemory, PerceptualMemory

#### 5. Tools
- **ToolRegistry**: регистрация инструментов
- **Builtin Tools**: встроенный набор
- **Base**: базовый класс и параметры

#### 6. Executors
- **ApplyPatchExecutor**: разбор и безопасное применение патчей

## 🚀 Быстрый старт

### Требования

- **Python**: 3.10+
- **ОС**: macOS / Linux / Windows

### Установка

#### 1. Клонирование

```bash
git clone <repository-url>
cd YYHDBL-HelloCodeAgentCli
```

#### 2. Виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
```

#### 3. Зависимости

```bash
pip install -r requirement.txt
```

#### 4. Переменные окружения

Создайте `.env`:

```bash
# LLM (обязательно)
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxx
```

#### 5. Запуск

```bash
# в текущем каталоге
python -m code_agent.hello_code_cli --repo .

# другой репозиторий
python -m code_agent.hello_code_cli --repo /path/to/your/project
```

## 📖 Руководство пользователя

### Базовое использование

После запуска — интерактивная консоль:

```
🚀 HelloAgents Code Agent CLI
📂 Repo: /path/to/project
💡 Введите 'help' для справки, 'exit' для выхода

👤 > Разбери точку входа в src/main.py

🤖 Thought: нужно прочитать файл
   Action: context_fetch[path=src/main.py]
   Observation: [содержимое файла]
   
   Thought: анализирую
   Action: Finish[результат анализа...]
```

### Демо

Видео: https://www.bilibili.com/video/BV1UzBpBBE75/

### Параметры CLI

```bash
python -m code_agent.hello_code_cli [OPTIONS]

Опции:
  --repo PATH              Путь к репозиторию (по умолчанию: текущий каталог)
  --model TEXT             Имя модели LLM
  --api-key TEXT           API-ключ
  --base-url TEXT          Базовый URL API
  --max-steps INTEGER      Макс. шагов рассуждения (по умолчанию: 15)
  --enable-memory          Включить память
  --enable-rag             Включить RAG
  --debug                  Режим отладки
  --help                   Справка
```
