# Промпты

Каталог для централизованного управления промптами Code Agent — удобно итерировать и сравнивать версии.

## Файлы
- `system.md` — глобальное поведение и границы безопасности (исследование по необходимости / подтверждение рискованных операций / формат патча)
- `react.md` — формат ReAct-цикла и соглашения по вводу инструментов
- `plan.md` — промпт инструмента планирования (`plan[...]`)
- `summarize_observation.md` — сжатие вывода инструментов

## Основная идея (в духе Claude Code)

### Исследование по необходимости
- **Базовый контекст** (авто): системный промпт + история диалога[-10:] + краткие итоги последних инструментов[-3:]
- **Расширенный контекст** (по запросу): через `context_fetch`, когда модель сама решает вызвать

### Руководство по context_fetch

**Когда использовать:**
- ✅ Поиск определений классов/функций в коде
- ✅ «Есть ли заметки/память про X»
- ✅ Стек ошибки — найти связанный код
- ❌ «О чём мы только что говорили» (достаточно истории диалога)
- ❌ Уже достаточно доказательств из terminal

**Параметры:**
```json
{
  "sources": ["files", "notes", "memory", "tests"],
  "query": "ContextBuilder",
  "paths": "context/**/*.py"
}
```

**Бюджет:** до ~800 tokens на источник, автообрезка, кэш

**Стратегия:** сначала базовый контекст; при нехватке доказательств — вызов; без слепого полного сканирования
