# Руководство по инструментам (краткая версия в духе Claude Code)

Встроенные инструменты: `terminal`, `context_fetch`, `todo`, `note`, `memory`, `plan`. Чётко: когда использовать / когда нет / как вызывать.

## terminal
Назначение: только чтение и быстрый просмотр (ls/rg/cat/sed/head/tail/grep/git status/diff).
- Когда: найти файл/символ/ошибку; небольшой фрагмент; структура каталогов.
- Когда нет: запись файлов (патч); полное сканирование репозитория без запроса; rm/chmod/git reset --hard.
- Пример: `terminal[{"command":"rg -n \"foo\" context/**/*.py","allow_dangerous":false}]`

## context_fetch
Назначение: агрегированный поиск (files/notes/memory/tests), авто-сжатие, контроль бюджета.
- Когда: нужно больше доказательств; класс/функция/стек; связанные заметки/память; меньше шагов, чем отдельные note/memory.
- Когда нет: доказательств уже достаточно; вопрос только про историю диалога.
- Пример: `context_fetch[{"sources":["files","notes"],"query":"ContextBuilder","paths":"context/**/*.py"}]`

## todo
Назначение: многошаговые задачи. Статусы: pending | in_progress (только 1) | completed.
- Когда: 3+ шага, несколько файлов/фич; список требований; задачи на несколько ходов; перед работой in_progress, по завершении completed.
- Когда нет: один простой шаг или чистый Q&A.
- Примеры:
  - `todo[{"action":"add","title":"Вёрстка страницы about","desc":"шапка/текст/навыки","status":"pending"}]`
  - `todo[{"action":"update","id":1,"status":"in_progress"}]`
  - `todo[{"action":"update","id":1,"status":"completed"}]`
  - `todo[{"action":"list"}]`

## note
Назначение: структурированные заметки (action/decision/blocker/task_state и т.д.), Markdown на диске.
- Когда: ключевые выводы/риски/блокеры; итог патча; этапное резюме.
- Когда нет: мелкие мысли можно оставить в диалоге.
- Пример: `note[{"action":"create","title":"Patch applied","content":"...","note_type":"action","tags":["patch"]}]`

## memory
Назначение: эпизодическая память (SQLite); между сессиями «что уже было». Автозапись выключена — только явный add.
- Когда: важно вспомнить позже; краткое резюме перед концом сессии; search перед повторным использованием опыта.
- Когда нет: краткосрочное уже в history; факты ещё не проверены.
- Примеры:
  - `memory[{"action":"add","memory_type":"episodic","content":"Стили hello.html обновлены, см. патч...","importance":0.7}]`
  - `memory[{"action":"search","query":"стили hello.html","memory_types":["episodic"],"limit":5}]`

## plan
Назначение: явное планирование, пошаговый план.
- Когда: неясная или явно многошаговая задача; пользователь просит план.
- Когда нет: тривиальный один шаг.
- Пример: `:plan добавить переключатель тёмной темы` или `plan[{"goal":"оптимизировать рендер: сначала узкие места, потом правки"}]`

## Важно
- Запись/изменение файлов — только патч (*** Begin Patch ...), не `cat >` / Here-Doc / tee / перенаправление.
- Сначала рассуждай на имеющемся контексте; лишние поиски не нужны.
- В todo только 1 in_progress; по завершении — completed; при блокере — новая запись с описанием.
