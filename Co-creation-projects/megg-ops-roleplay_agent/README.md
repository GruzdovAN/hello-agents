# Иммерсивный roleplay-агент (версия на Python)

Иммерсивный roleplay-агент на Python: диалог с пользовательскими персонажами. Поддерживаются модели с совместимым OpenAI API.

## Возможности

- 🎭 Гибкая настройка персонажа
- 🧠 Поддержка разных моделей ИИ (совместимый OpenAI API)
- 📝 Имя, произведение-источник, черты характера и другие параметры
- 💬 Иммерсивный диалог
- 🔁 Переключение между несколькими персонажами

## Требования

- Python 3.8 или выше
- API-ключ сервиса модели с совместимым OpenAI API

## Установка

1. Клонируйте или скачайте проект локально

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте API:
   - создайте файл `.env` в корне проекта
   - добавьте:
   ```
   LLM_API_KEY=ваш_реальный_API_ключ
   LLM_MODEL_ID=ID_модели (например: gpt-3.5-turbo, claude-3-opus и т.д.)
   LLM_BASE_URL=базовый_URL_API (опционально; для стандартного OpenAI не нужен)
   ```

## Использование

1. Запустите основную программу:
   ```bash
   python roleplay_agent.py
   ```

2. Введите данные персонажа по подсказкам:
   - имя персонажа
   - произведение-источник
   - характер и черты
   - вступительная реплика (опционально)

3. Начните диалог:
   - вводите сообщения для общения с персонажем
   - `quit` или `exit` — выход
   - `new` — новый персонаж
   - `reset` — сброс текущего диалога

## Поддерживаемые сервисы моделей

Приложение совместимо с любым сервисом в формате OpenAI API, например:
- OpenAI GPT
- Azure OpenAI
- Anthropic Claude (через совместимый слой)
- самохостинг (Ollama, LocalAI и т.д.)
- другие совместимые провайдеры

```

Вы: Здравствуй, Великий мудрец!

```

## Описание конфигурации

- **LLM_API_KEY**: API-ключ вашего сервиса моделей
- **LLM_MODEL_ID**: ID модели (например, gpt-4, claude-3-opus)
- **LLM_BASE_URL**: базовый URL API (нужен для нестандартных OpenAI-совместимых сервисов)

## Примечания

- Убедитесь, что API-ключ действителен и есть права на использование
- Содержимое от ИИ может быть вымышленным — относитесь критически
- Следите за квотами API
- Для лучшего эффекта подстройте `temperature` и другие параметры под выбранную модель
