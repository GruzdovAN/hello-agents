# 🍳 Умный помощник по рецептам (Smart Recipe Agent)

> Мультиагентная система на фреймворке `hello_agents`: автоматический поиск, отбор и формирование полных рецептов

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

---

## 📋 О проекте

**Умный помощник по рецептам** — система поиска рецептов на основе совместной работы нескольких агентов (Agent). Достаточно указать пищевые предпочтения (например, «хочу раков» или «домашние блюда для снижения «жара» в организме»), и система автоматически:

1. 🔍 **Ищет рецепты**: вызывает инструмент веб-поиска и получает список рецептов
2. 🎯 **Умно отбирает**: рекомендует наиболее подходящий рецепт с учётом предпочтений
3. 📄 **Извлекает содержимое**: загружает полный рецепт и сохраняет в Markdown

Все сгенерированные рецепты сохраняются в каталоге `recipes/` для удобного просмотра.

---

## ✨ Ключевые возможности

- 🤖 **Мультиагентное взаимодействие**: эксперт по поиску + диетолог + эксперт по извлечению контента
- 🔗 **Реальные источники**: сайты вроде xiangha.com, без выдуманных данных
- 📝 **Структурированный вывод**: название, ссылка, обоснование рекомендации
- 💾 **Автосохранение**: рецепты в Markdown с меткой времени
- 🔧 **Расширяемая архитектура**: протокол MCP, легко подключать новые источники

## ⚙️ Конфигурация

### Формат вызова инструментов

Агенты поиска и вывода используют единый формат:

```
[TOOL_CALL:visit_page:url=https://www.xiangha.com/so/?q=caipu&s=ключевое_слово]
```

**Параметры:**
- `visit_page`: имя инструмента
- `url`: адрес страницы — поиск на xiangha.com или конкретный рецепт

### Правила разбора ответа

Функция `parse_response()` поддерживает чистую JSON-строку (с `{}`)

При ошибке разбора выводится предупреждение и возвращается `None`; основной поток проверяет пустые значения.

## 🎯 Рекомендации по вводу

### Удачные формулировки
```
✅ «Низкокалорийные рецепты для похудения»
✅ «Быстрый завтрак за 10 минут»
✅ «Сычуаньская кухня, слегка острое, с курицей»
✅ «Мягкие блюда для пожилых, легко перевариваются»
```

### Чего лучше избегать
```
❌ «Приготовь что-нибудь»  # слишком расплывчато
❌ «Придумай несуществующее блюдо»  # система не выдумывает данные
❌ Прямой запрос «напиши рецепт тушёной свинины»  # нужен поиск по реальным источникам
```

## 🔧 Расширение

### Новый источник данных
Измените URL-шаблон в `system_prompt` агента:
```python
# Пример: поддержка xiachufang.com
[TOOL_CALL:visit_page:url=https://www.xiachufang.com/search/?keyword=ключевое_слово]
```

### Своя логика отбора
Настройте prompt `caipu_select_agent`:
```
- Приоритет рецептам с временем готовки < 30 минут
```
