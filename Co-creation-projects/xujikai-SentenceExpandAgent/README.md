# Агент расширения английских предложений

> Многоагентный «тренер письма»: метод журналистских вопросов превращает простое предложение в развёрнутое

## 📝 О проекте

Инструмент для изучения английского письма с многоагентной архитектурой, имитирующей урок:

- **Какую проблему решает?**
  - Простые предложения без вариативности
  - Нет системной обратной связи в традиционных упражнениях
  - Сложно освоить пошаговое расширение от простого к сложному

- **Особенности**
  - Метод журналиста: три этапа целевых вопросов
  - Два режима: ручной (пошагово) и автоматический (демо одним кликом)
  - Грамматический разбор в реальном времени
  - Финальная полировка по трём раундам расширения

- **Сценарии**
  - Обучение письму
  - Техника расширения предложений
  - Продвинутая грамматика
  - Самообучение и работа преподавателя

## ✨ Основные возможности

- [x] **Ручной режим**: поэтапные ответы на вопросы журналиста
- [x] **Автоматический режим**: полный цикл одним кликом
- [x] **Три этапа расширения**:
  - Этап 1: детали (прилагательные, наречия и др.)
  - Этап 2: время и место (предложные обороты)
  - Этап 3: глубина структуры (причастия, определительные и обстоятельственные придаточные)
- [x] **Грамматический разбор**: оценка и исправления
- [x] **Финальная полировка**: «идеальное» предложение и разбор структуры
- [x] **SSE**: потоковая передача в автоматическом режиме

## 🛠️ Стек

### Фронтенд
- **Vue 3**
- **TypeScript**
- **Vite**
- **Pinia**
- **SSE** для автоматического режима

### Бэкенд
- **FastAPI**
- **HelloAgents**
- **Pydantic**

### Архитектура агентов

1. **OrchestratorAgent (оркестратор)**
   - Планирование потока и состояние
   - Координация агентов
   - Стратегия следующего этапа

2. **InterviewerAgent (журналист)**
   - Вопросы по этапу
   - Подсказки по грамматике и примеры перефразирования

3. **EvaluatorAgent (оценка грамматики)**
   - Проверка предложений ученика
   - Комментарии и исправления
   - Соответствие цели этапа

4. **PolisherAgent (полировка)**
   - Все три раунда расширения
   - Итоговое предложение и разбор

5. **AutoModeAgent (автодемо)**
   - Три раунда без участия пользователя
   - Имитация ответов и обратной связи
   - Прогресс через SSE

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Node.js 16+
- npm или yarn

### Бэкенд

1. **Каталог бэкенда**
```bash
cd backend
```

2. **Виртуальное окружение**
```bash
python -m venv .venv
```

3. **Активация**
```bash
# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate
```

4. **Зависимости**
```bash
pip install -r requirements.txt
```

5. **Переменные окружения**
```bash
cp .env.example .env
# Заполните API в .env
```

6. **Запуск**
```bash
python src/main.py
```

Бэкенд: `http://localhost:8000`

### Фронтенд

1. **Каталог фронтенда**
```bash
cd frontend
```

2. **Зависимости**
```bash
npm install
```

3. **Переменные окружения**
```bash
cp .env.example .env
# VITE_API_BASE_URL=http://localhost:8000
```

4. **Dev-сервер**
```bash
npm run dev
```

Фронтенд: `http://localhost:3000` (порт в выводе терминала)

### Доступ

Откройте адрес фронтенда в браузере.

## 📖 Примеры

### Ручной режим

1. **Исходное предложение**
   ```
   I like reading.
   ```

2. **Ручной режим → старт**

3. **Этап 1 — детали**
   - Вопрос: «Насколько сильно и какие книги/жанры?»
   - Ответ: `I really like reading science fiction novels.`
   - Разбор: «Отлично: наречие `really`, составное прилагательное `science fiction` — цель этапа достигнута.»

4. **Этап 2 — время и место**
   - Вопрос: «Когда и где обычно читаете фантастику?»
   - Ответ: `I really like reading science fiction novels in my free time at my home.`
   - Разбор: «Сохранены модификаторы, добавлены время и место, предлоги верны.»

5. **Этап 3 — глубина структуры**
   - Вопрос: «Что привлекает в фантастике или почему читаете?»
   - Ответ: `I really like reading science fiction novels in my free time at my home because they stimulate my imagination and take me to new worlds.`
   - Разбор: «Сильный финал: придаточное причины справа, тема соблюдена.»

### Автоматический режим

1. **Исходное предложение**
   ```
   She enjoys music.
   ```

2. **Автоматический режим → старт**

3. **Демо**
   - Три этапа автоматически
   - Вопросы, ответы и разбор в реальном времени
   - Итоговое «идеальное» предложение
