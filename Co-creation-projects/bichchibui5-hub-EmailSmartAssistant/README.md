# Умный почтовый помощник (EmailSmartAssistant)

> AI-система обработки почты: автоклассификация, черновики ответов, извлечение ключевой информации и умные напоминания

## 📝 О проекте

Умный почтовый помощник — инструмент автоматизации на Python и машинном обучении для повышения эффективности работы с почтой на работе и дома.

**Решаемые задачи:**
- 📧 Большой объём писем, ручная сортировка отнимает время
- ✍️ Ответы под разные ситуации требуют усилий, сложно сохранить профессиональный тон
- ⏰ Важные сроки и follow-up теряются из-за забывчивости
- 🔍 Ключевая информация разбросана по письмам, её трудно быстро собрать

**Особенности:**
- 🤖 Классификация и приоритет на основе NLP
- 📝 Черновики ответов на разных языках и в разных сценариях
- 📅 Извлечение дат и создание напоминаний
- 📊 Визуальные отчёты по обработке почты

**Сценарии:**
- Корпоративная почта
- Обслуживание клиентов
- Личный ящик
- Follow-up по проектной переписке

## ✨ Основные функции

- [x] **Умная классификация**: тип (работа/клиент/личное/спам), приоритет (высокий/средний/низкий), тип отправителя
- [x] **Генерация ответов**: черновики по смыслу письма, китайский/английский, формальный/неформальный тон
- [x] **Извлечение данных**: даты, время, контакты, задачи
- [x] **Напоминания**: на основе извлечённого времени, настраиваемое опережение
- [x] **Отчёты**: графики и структурированные сводки
- [x] **Несколько ящиков**: Gmail, Outlook, QQ Mail и др.

## 🛠️ Стек технологий

- **Ядро**: Python 3.8+
- **Фреймворк агентов**: HelloAgents (парадигма ReAct)

- **ML**: scikit-learn, sentence-transformers

- **Визуализация**: matplotlib, seaborn, plotly

- **Время**: dateparser, arrow

## 🚀 Быстрый старт

### Требования

- Python 3.8+
- Jupyter Notebook
- Учётная запись с IMAP/SMTP (опционально)

### Установка

```bash
pip install -r requirements.txt
```

### Демо

Без настройки почты — все функции в демо:

```bash
# Упрощённое демо (рекомендуется)
python demo.py

# Полное демо (нужны зависимости)
jupyter notebook EmailSmartAssistant.ipynb
```

### Настройка почты (опционально)

Для реальной почты укажите параметры:

```bash
# Файл конфигурации
# config/email_config.json
```

Типичные настройки:

| Сервис | IMAP-сервер | IMAP-порт | SMTP-сервер | SMTP-порт |
|---------|-----------|---------|-----------|---------|
| Gmail | imap.gmail.com | 993 | smtp.gmail.com | 587 |
| Outlook | outlook.office365.com | 993 | smtp.office365.com | 587 |
| QQ Mail | imap.qq.com | 993 | smtp.qq.com | 587 |

### Запуск

```bash
# Jupyter Notebook
jupyter notebook

# Варианты:
# 1. EmailSmartAssistant.ipynb — полная оригинальная версия
# 2. EmailSmartAssistant_HelloAgents.ipynb — на HelloAgents
```

## ⚠️ Важно

### Безопасность
- **Пароль приложения**: не основной пароль ящика
- **Конфиги**: не коммитьте файлы с паролями
- **Сеть**: запускайте в доверенной среде

### Пароли приложений
- **Gmail**: Аккаунт Google → Безопасность → Пароли приложений
- **Outlook**: Учётная запись Microsoft → Безопасность → Пароли приложений
- **QQ Mail**: Настройки → Аккаунт → IMAP/SMTP

### Устранение неполадок

#### Ошибка подключения
- Проверьте адрес и порт сервера
- Включён ли IMAP/SMTP
- Верность пароля приложения
- Файрвол и сеть

#### Проблемы с зависимостями
```bash
# При сбое pip — conda
conda install pandas numpy matplotlib seaborn
pip install -r requirements.txt

# Или зеркало Tsinghua
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
```
