# Academic-Data-Agent

> Агент (Agent) анализа научных данных: таблицы и извлечение главных таблиц из PDF-статей.

## 📝 О проекте

Academic-Data-Agent — рабочее место для анализа научных данных по идеям Hello-Agents. Связывает загрузку данных, выполнение анализа, отчёты и рецензирование в один процесс. Поддерживает структурированные таблицы `csv / xls / xlsx` и текстовые PDF.

Для PDF используется не просто одна таблица, а режим «главная таблица + контекст статьи + сводки кандидатов»:

- Автоизвлечение аннотации или вводного контекста
- Распознавание кандидатов и выбор одной главной для количественного анализа
- Остальные таблицы — как контекст для интерпретации отчёта

Текущая community-версия — компактная демо-сборка для быстрого воспроизведения в Hello-Agents; полная версия с Gradio, историей и расширенной инженерией:

- Полная версия: [My-Academic-Data-Agent](https://github.com/healer-666/My-Academic-Data-Agent)

## ✨ Основные функции

- [x] Автоанализ таблиц: `csv / xls / xlsx`
- [x] Разбор PDF: кандидаты, выбор главной таблицы, контекст статьи
- [x] Структурированные отчёты: Markdown, графики и trace
- [x] Лёгкое рецензирование: `draft / standard / publication`
- [x] Ограничения для малых таблиц в PDF: меньше ложных статистических тестов на сводных результатах

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Рекомендуется виртуальное окружение

### Установка

```bash
pip install -r requirements.txt
```

### API Key

```bash
cp .env.example .env
```

В `.env` укажите как минимум:

```env
LLM_MODEL_ID=your_model_id
LLM_BASE_URL=https://your-openai-compatible-endpoint/v1
LLM_API_KEY=your_api_key
```

Для веб-поиска контекста или визуального рецензирования:

```env
TAVILY_API_KEY=your_tavily_api_key
VISION_LLM_MODEL_ID=your_vision_model
VISION_LLM_BASE_URL=https://your-vision-endpoint/v1
VISION_LLM_API_KEY=your_vision_api_key
```

### Запуск

```bash
jupyter lab
```

Откройте `main.ipynb` и выполните ячейки по порядку.

## 📖 Примеры

В Notebook два демо:

1. Excel — стандартный анализ таблицы
2. PDF — кандидаты, выбор главной таблицы и сводный отчёт

По умолчанию лёгкая конфигурация:

- `quality_mode="draft"`
- `latency_mode="auto"`

Удобно для быстрого воспроизведения в community-ревью.

## 🎯 Преимущества

- От «одноразового скрипта» к отслеживаемому рабочему процессу
