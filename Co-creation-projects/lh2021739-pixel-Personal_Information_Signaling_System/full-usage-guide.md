# Система извлечения измерений и корректировки тем — полный рабочий процесс

## Обзор системы

Система реализует полный цикл: извлечение измерений из отчётов пользователя и корректировка тем поиска YouTube (themes) на основе анализа измерений.

**Основной процесс**:
1. Пользователь пишет ежедневный/еженедельный/ежемесячный отчёт (естественный язык)
2. LLM извлекает измерения из отчёта
3. Анализ измерений сравнивается с существующими themes
4. Генерируются рекомендации по корректировке themes (добавление/удаление)
5. После подтверждения пользователем обновляется themes.yaml

## Описание файлов

### Основные скрипты

1. **`write_report.py`** — инструмент написания отчётов
   - Создание ежедневных/еженедельных/ежемесячных отчётов
   - Интерактивный ввод, сохранение в Markdown

2. **`extract_dimensions.py`** — извлечение измерений
   - Извлечение измерений из отчётов с помощью LLM
   - Пакетная обработка файлов отчётов

3. **`manage_themes.py`** — управление темами
   - Управление файлом themes.yaml
   - Добавление/удаление/просмотр themes

4. **`analyze_dimensions.py`** — основной инструмент анализа
   - Объединяет извлечение и анализ измерений
   - Генерирует рекомендации по корректировке themes
   - Поддерживает интерактивное подтверждение и применение

### Структура данных

```
Personal_Information_Signaling_System/
├── themes.yaml                    # Темы поиска, заданные пользователем
├── archive/
│   ├── reports/                   # Отчёты пользователя (Markdown)
│   │   ├── daily/                 # Ежедневные
│   │   ├── weekly/                # Еженедельные
│   │   └── monthly/               # Ежемесячные

│       └── YYYY-MM-DD_analysis.json
```

## Полный рабочий процесс

### Шаг 1: Написание отчёта

Создайте отчёт с помощью `write_report.py`:

```bash
python write_report.py
```

Выберите действие:
- 1. Создать ежедневный отчёт
- 2. Создать еженедельный отчёт
- 3. Создать ежемесячный отчёт

Введите содержание отчёта (естественный язык, Markdown) — система сохранит автоматически.

**Альтернатива**: создайте или отредактируйте `.md` файл напрямую в `archive/reports/`:
- ежедневный: `YYYY-MM-DD.md`
- еженедельный: `YYYY-Www.md`
- ежемесячный: `YYYY-MM.md`

### Шаг 2: Извлечение измерений

Извлеките измерения из отчётов:

```bash
# Извлечь измерения из всех отчётов
python extract_dimensions.py

# Только из ежедневных отчётов
python extract_dimensions.py --report-type daily

# Из одного файла отчёта
python extract_dimensions.py --report-file archive/reports/daily/2025-12-28.md
```

Результаты сохраняются в `archive/dimensions/`.

### Шаг 3: Анализ измерений и рекомендации по themes

Запустите основной инструмент анализа:

```bash
# Базовый анализ (загрузка уже извлечённых результатов)
python analyze_dimensions.py

# Повторное извлечение и анализ
python analyze_dimensions.py --extract

# Интерактивный режим (просмотр и обработка рекомендаций)
python analyze_dimensions.py --interactive

# Комбинация
python analyze_dimensions.py --extract --interactive
```

### Шаг 4: Управление themes (опционально)

Ручное управление themes:

```bash
# Интерактивное управление
python manage_themes.py

# Операции из командной строки
python manage_themes.py --list              # Список всех themes
python manage_themes.py --add "健康"        # Добавить theme
python manage_themes.py --remove "娱乐"     # Удалить theme
```

## Критерии корректировки тем

### Рекомендация добавить theme

Условия:
- измерение встречается в результатах извлечения с частотой ≥ 50%;
- за последние 30 дней — ≥ 3 раз;
- измерение отсутствует в существующих themes.

### Рекомендация удалить theme

Условия:
- доля совпадений theme в извлечённых измерениях < 10%;
- период наблюдения ≥ 60 дней;
- за последние 90 дней совпадений мало.

## Типичные сценарии

### Ежедневное использование

```bash
# 1. Ежедневный отчёт
python write_report.py
# Выберите 1, введите содержание за сегодня

# 2. Раз в неделю — извлечение измерений
python extract_dimensions.py

# 3. Анализ и просмотр рекомендаций
python analyze_dimensions.py --extract --interactive
```

### Первоначальная настройка

```bash
# 1. Начальные themes (вручную в themes.yaml или через инструмент)
python manage_themes.py

# 2. Напишите несколько отчётов
python write_report.py

# 3. Извлеките измерения
python extract_dimensions.py

# 4. Проанализируйте и примените рекомендации
python analyze_dimensions.py --extract --interactive
```

## Требования к конфигурации

### Настройка LLM

В `.env` укажите LLM (для извлечения измерений):

```env
LLM_API_KEY=your-api-key
LLM_MODEL=qwen-plus
LLM_BASE_URL=https://api-inference.modelscope.cn/v1/
LLM_PROVIDER=modelscope
```

### Конфигурация themes

Формат файла `themes.yaml`:

```yaml
themes:
  - mcp
  - agent
  - rag
  - money
  - AI
```

## Описание выходных файлов

### Результат извлечения измерений

`archive/dimensions/YYYY-MM-DD_type_dimensions.json`:

```json
{
  "report_date": "2025-12-28",
  "report_type": "daily",
  "report_file": "archive/reports/daily/2025-12-28.md",
  "extracted_dimensions": ["健康", "情绪", "工作"],
  "confidence": 0.85,
  "extraction_date": "2025-12-28T10:00:00Z"
}
```

### Отчёт анализа

`archive/dimension_analysis/YYYY-MM-DD_analysis.json`:

Содержит статистику измерений, анализ соответствия themes, рекомендации по корректировке и др.

## Примечания

1. **Первый запуск**: сначала напишите несколько отчётов и извлеките измерения — только тогда рекомендации будут осмысленными
2. **Настройка LLM**: для извлечения измерений нужен LLM — убедитесь, что API Key настроен
3. **Формат отчётов**: Markdown с заголовками, абзацами, списками и т.д.
4. **Извлечение**: каждый запуск `extract_dimensions.py` перезаписывает предыдущие результаты
5. **Обновление themes**: в интерактивном режиме внимательно проверяйте каждую рекомендацию перед применением

## Устранение неполадок

### Ошибка инициализации LLM

- Проверьте API Key в `.env`
- Убедитесь в наличии сетевого подключения
- Проверьте квоту API

### Измерения не извлечены

- Убедитесь, что файл отчёта существует и не пуст
- Проверьте формат файла отчёта
- Попробуйте извлечь один файл отдельно и посмотрите сообщение об ошибке

### Рекомендации не сгенерированы

- Нужно достаточно результатов извлечения (рекомендуется минимум 3–5 отчётов)
- Проверьте, что themes настроены
- Посмотрите статистику в отчёте анализа
