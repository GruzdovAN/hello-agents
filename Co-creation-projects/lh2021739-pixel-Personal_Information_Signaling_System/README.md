# Описание изображения напоминания

## Требования к изображению

Поместите изображение персонажа в эту директорию с одним из следующих имён:

- `person.png` (рекомендуется, поддерживается прозрачный фон)
- `person.jpg`
- `person.jpeg`
- `reminder.png`
- `reminder.jpg`

## Рекомендуемые параметры изображения

- **Формат**: PNG (рекомендуется, поддерживается прозрачный фон) или JPG
- **Размер**: от 200×200 до 400×400 пикселей
- **Фон**: прозрачный (PNG) или однотонный
- **Содержание**: фотография человека или мультяшный персонаж

## Инструкция по использованию

1. Переименуйте файл изображения в одно из указанных выше имён
2. Поместите его в директорию `assets/`
3. Запустите `daily_reminder.py` — изображение будет отображаться

## Анимация моргания

Система автоматически добавляет анимацию моргания в области глаз на изображении; дополнительные кадры не требуются.
