# Руководство по системе анализа измерений (V1, упрощённая версия)

## Обзор функций

Система анализа измерений позволяет:
1. Собирать и анализировать данные измерений из записей пользователя (ежедневные/еженедельные/ежемесячные отчёты)
2. Считать частоту появления измерений
3. Автоматически генерировать рекомендации по управлению измерениями (добавление/удаление/корректировка приоритета)
4. Подтверждать рекомендации в интерактивном режиме
5. Вести историю эволюции измерений

## Быстрый старт

### 1. Подготовка данных

Убедитесь, что JSON ежедневного отчёта содержит поле `dimensions` (необязательно):

```json
{
  "date": "2025-12-28",
  "themes_used": ["mcp", "agent"],
  "dimensions": ["健康", "情绪", "工作"],
  "top3": [...],
  "action": "...",
  "risk": "..."
}
```

### 2. Файл конфигурации

Создайте `dimension_config.json` (если файла нет, система создаст конфигурацию по умолчанию):

```json
{
  "active_dimensions": [
    {
      "name": "健康",
      "priority": 0.75,
      "added_date": "2025-12-01",
      "last_seen": null
    }
  ],
  "candidate_dimensions": ["娱乐", "学习"],
  "removed_dimensions": []
}
```

### 3. Запуск анализа

```bash
# Базовый анализ (генерация отчёта)
python analyze_dimensions.py

# Интерактивный режим (просмотр и обработка рекомендаций)
python analyze_dimensions.py --interactive

# Показать историю
python analyze_dimensions.py --show-history

# Комбинация
python analyze_dimensions.py --interactive --show-history
```

## Результаты

### Отчёт анализа

Сохраняется в `archive/dimension_analysis/YYYY-MM-DD_analysis.json` и содержит:

- `dimension_statistics`: статистика измерений (частота, даты появления и т.д.)
- `suggestions`: рекомендации системы
  - `add`: добавить измерение
  - `remove`: удалить измерение
  - `priority_adjustment`: скорректировать приоритет
- `history_summary`: краткая сводка по истории

### Файлы конфигурации

- `dimension_config.json`: конфигурация измерений (активные, кандидаты и т.д.)
- `dimension_history.json`: история эволюции измерений

## Правила генерации рекомендаций

1. **Добавить измерение**: кандидат из списка не появлялся в записях более 30 дней
2. **Удалить измерение**: активное измерение не появлялось более 60 дней
3. **Скорректировать приоритет**: частота > 70%, а текущий приоритет < частоты

## Расчёт приоритета

Приоритет = частота появления = число появлений измерения / общее число записей

Диапазон: 0.0 – 1.0

## Интерактивный режим

С параметром `--interactive` система:

1. Показывает все рекомендации
2. По каждой спрашивает: принять (y) / отклонить (n)
3. Применяет принятые рекомендации
4. Обновляет конфигурацию и историю

## Примечания

1. **Обратная совместимость**: если в JSON ежедневного отчёта нет `dimensions`, система добавит пустой массив
2. **Формат данных**: еженедельные и ежемесячные отчёты используют тот же JSON-формат (опционально)
3. **Конфигурация**: при отсутствии файла используется конфигурация по умолчанию
4. **История**: сохраняется автоматически, просмотр в любой момент
