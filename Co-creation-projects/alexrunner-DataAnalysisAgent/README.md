# Агент анализа продаж товаров

> Для сценария анализа продаж: профессиональный агент (Agent) с автоматическим анализом, визуализацией и бизнес-отчётом.

## 📝 Описание проекта

- В розничных продажах анализ сложен, вручную долго, отчёты неединообразны. Агент анализирует данные одной командой и выдаёт наглядный отчёт — выше качество, меньше времени.
- Агент выявляет связи в данных и формирует ключевые подзадачи; вызывает инструменты анализа, строит графики; собирает итоговый отчёт.
- Подходит для глубокого анализа сложных данных о продажах и бизнес-консультаций.

## ✨ Основные возможности

- [x] Быстрое выделение ключевой информации и постановка аналитических задач
- [x] Инструменты анализа: связи в данных, выводы по задачам
- [x] Автоматический отчёт с текстом и иллюстрациями

## 🛠️ Технологический стек

- Фреймворк HelloAgents
- Парадигмы агентов:
    - В целом **Plan-and-Solve**: агент Plan планирует подзадачи, Analysis вызывает инструменты, Report собирает форматированный отчёт
    - Plan и Analysis на архитектуре **ReAct (ReAct)**: многошаговое рассуждение и вызов инструментов
    - Report — простой агент без инструментов, формирует отчёт по выводам задач
- Инструменты и API:
    - Разведка и анализ — обёртки на Python
    - Внешние API не используются

## 📖 Примеры

### Код

Пример агента планирования:

```python
from hello_agents import HelloAgentsLLM

from agents.react_agent import NewReActAgent
from agents.agent_prompts import PLAN_AGENT_PROMPT
from tools.data_exploration import create_data_exploration_registry


if __name__ == "__main__":
    llm = HelloAgentsLLM()
    registry = create_data_exploration_registry()
    planning_agent = NewReActAgent(
        name="PlanningAgent",
        llm=llm,
        custom_prompt=PLAN_AGENT_PROMPT,
        tool_registry=registry,
        max_steps=5
    )

    question = "Начните анализ"
    try:
        plan_result = planning_agent.run(question)
        print(f"План задач: {plan_result}")
    except Exception as e:
        print(f"Ошибка при выполнении: {e}")
```

## 🎯 Сильные стороны

- Plan-and-Solve + ReAct: планирование отделено от исполнения, на нижнем уровне — ReAct
- Переписан ReAct: JSON в промпте, выше успех извлечения; при лимите шагов — итоговый вывод из истории, а не ошибка
- Промпты Plan / Analysis / Report и тесты для отладки
