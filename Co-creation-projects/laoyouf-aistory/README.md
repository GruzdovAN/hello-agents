# Название проекта

> Генератор историй (роман / сценарий / стихи)

## 📝 О проекте

Описание проекта:
- Какую задачу решает? По жанру, теме и стилю пользователя генерирует текст в нужной форме.
- Чем отличается? Настраиваемые жанр, тема и стиль.
- Где применять? Развлечение и творческие эксперименты.



## 🛠️ Стек технологий

- Фреймворк HelloAgents


## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Прочие зависимости по окружению

### Установка зависимостей

\`\`\`bash
pip install -r requirements.txt
\`\`\`

### Настройка API-ключей

\`\`\`bash
# Создать файл .env
cp .env.example .env

# Отредактировать .env и указать API-ключи
\`\`\`

### Запуск

\`\`\`bash
# Запустить Jupyter Notebook
jupyter lab

# Открыть main.ipynb и выполнить
\`\`\`
