# Аналитик отношений (Love Analyst Agent)
## 📖 О проекте
Интеллектуальный агент на базе большой языковой модели для пользователей на стадии флирта или в отношениях.
- **Какую задачу решает?** По загруженной переписке оценивает симпатию собеседника, скрытые намерения и эмоциональное состояние — ответы на «нравлюсь ли я ему/ей» и «что значит эта фраза».
- **Чем отличается?** Количественный «индекс влюблённости», разбор подтекста и варианты ответов с высоким EQ с учётом характера собеседника.
- **Где применять?** Флирт, разбор конфликтов в паре, разбор после свидания, улучшение повседневной переписки.
## ✨ Основные возможности
- [ ] **Глубокий разбор переписки**: загрузка текста из WeChat/QQ и др.; агент очищает данные и выделяет ключевые эмоциональные моменты.
- [ ] **Оценка индекса симпатии**: по частоте сообщений, близости лексики, эмоциональной ценности — оценка 0–100 и радарный анализ.
- [ ] **Генерация ответов с высоким EQ**: для тупика или конкретной темы — варианты в разных стилях (юмор, нежность, «push-pull»).
## 🛠️ Стек
- **Фреймворк**: HelloAgents
- **Парадигма**: ReAct (рассуждение + действие с базой психологии), Plan-and-Solve (планирование сложных конфликтов)
- **Инструменты и API**:
    - LLM API 
    - LangChain (обработка текста и цепочки вызовов)
    - Matplotlib/Seaborn (визуализация анализа эмоций)
- **Прочее**: Pydantic, python-dotenv, JupyterLab
