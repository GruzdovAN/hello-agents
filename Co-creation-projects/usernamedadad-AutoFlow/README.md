# Инструмент генерации блок-схем (AutoFlow)

> Из естественного языка в Mermaid: генерация и предпросмотр в реальном времени.

## 📝 О проекте

AutoFlow — проект с разделением фронтенда и бэкенда: идеи, требования или планы в тексте быстро превращаются в рендерируемые Mermaid-диаграммы.

Решает три задачи:

- Низкая скорость «текст → диаграмма»
- Высокая стоимость и ошибки при ручном Mermaid
- Нет единой структуры и визуальной обратной связи

Сценарии:

- Сбор и согласование требований
- Процессы продукта и операций
- Обучение и структурирование знаний
- Визуализация задач проекта

## ✨ Основные возможности

- Режим вдохновения: идея → дополнение и диаграмма
- Стандартный режим: оптимизация промпта → код Mermaid
- Режим плана: шаги построчно → линейная диаграмма
- Режим кода Mermaid: прямой ввод и рендер
- Направление и предпросмотр: сверху вниз / слева направо, масштаб, перетаскивание, экспорт

## 🛠️ Стек

- Агенты: HelloAgents
- Бэкенд: FastAPI + SSE
- Фронтенд: React + Vite + Mermaid
- Ядро: оптимизация промптов, структурированная генерация, проверка и исправление синтаксиса

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Node.js 18+
- npm 9+

### Установка

Бэкенд:

```bash
pip install -r requirements.txt
```

Фронтенд:

```bash
npm install
```

### API-ключ

В каталоге `backend` создайте `.env` (см. `.env.example`), минимум:

- LLM\_MODEL\_ID
- LLM\_API\_KEY
- LLM\_BASE\_URL
- LLM\_TIMEOUT

### Запуск

1. Бэкенд

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

1. Фронтенд

```bash
npm run dev
```

1. Браузер (по умолчанию)

- <http://localhost:5173>
