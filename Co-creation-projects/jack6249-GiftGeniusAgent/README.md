# 🎁 GiftGenius: умный помощник по подаркам

Мультиагентная система на базе HelloAgents: точные и продуманные рекомендации подарков.

## 📝 О проекте

GiftGenius — агент (Agent) рекомендаций подарков, который решает вечный вопрос «что подарить». Это не простой поиск по ключевым словам, а мультиагентный конвейер (Multi-Agent Pipeline), имитирующий человеческое принятие решений.

Цепочка «стратег» (план) → «охотник» (поиск в сети) → «редактор» (очистка данных и тексты) строит персональный гид по подаркам с картинками и ценами — с учётом MBTI, знака зодиака, бюджета и других параметров получателя.

- Какую проблему решает?

   Сложность выбора подарка, устаревшие товары, превышение бюджета, скучные описания.

- Чем отличается?

   Анализ по MBTI/зодиаку, автоматическое сравнение цен и поиск аналогов, извлечение данных с защитой от галлюцинаций.

- Где применять?

  Праздники, дни рождения, годовщины и любые сценарии с персональными рекомендациями.

## ✨ Основные возможности

- [x] Точный портрет получателя: MBTI, знак зодиака, возраст — стратегия поиска под предпочтения.

- [x] Контроль бюджета: диапазон вроде «500–1000 юаней» и «ценовой страж» — отсекает дорогие позиции и запускает поиск аналогов.

- [x] Поиск в сети в реальном времени: Tavily — актуальные товары, цены и изображения 2025 года.

- [x] Наглядный отчёт: Markdown-таблица с фото, ценами и продающими текстами.

## 🚀 Быстрый старт

### Требования

Python 3.10+

Jupyter Notebook / Jupyter Lab

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка API-ключей

Скопируйте шаблон конфигурации:

```bash
# Создать файл .env
cp .env.example .env
# Отредактировать .env и указать API-ключи
```



### Запуск

Заполните `user_profile.json` данными о получателе (MBTI, бюджет и т.д.).

Запустите Jupyter Notebook:

```bash
jupyter notebook main.ipynb
```
По умолчанию используется Baidu Premium MCP; можно переключить на Tavily Search API.
```py
# Источник поиска
# Допустимые значения: "tavily" (универсальный/зарубежный) или "baidu" (e-commerce/Китай)
os.environ["SEARCH_PROVIDER"] = "baidu" 
```


Нажмите «Run All» — итог в `outputs/gift_plan_output.md`.

## 🎯 Сильные стороны

- Двухпоточная архитектура (Dual-Stream): «жёсткий» поиск цен и «мягкая» генерация текстов — параллельно, меньше шума в контексте, выше качество описаний.

- Защита от галлюцинаций на уровне кода (Code-based Guardrails): JSON не от LLM напрямую — цены и картинки извлекаются регулярными выражениями из результатов поиска.

- Динамическая коррекция стратегии (Feedback Loop): «ценовой страж» при средней цене выше бюджета снова вызывает «стратега» на план с аналогами, пока не найдётся подходящее.

- Несколько источников данных: Baidu Premium MCP и Tavily Search API.
