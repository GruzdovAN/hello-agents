# Умный агент (Agent) конкурентного анализа

> Интеллектуальная система анализа конкурентов на Hello Agents: парадигмы **SimpleAgent** и **PlanAndSolveAgent** — сбор данных, многомерное сравнение и профессиональный отчёт.

## 📝 О проекте

Проект предлагает **два варианта агента (Agent)** под разные задачи:

| Реализация | Особенности | Сценарии |
|---------|------|---------|
| **SimpleAgent** | Прямой вызов инструментов, быстрый отклик | Быстрые запросы, простой анализ |
| **PlanAndSolveAgent** | Сначала план, затем шаги | Глубокий анализ, сложные задачи |

Агент конкурентного анализа решает типичные проблемы:

- **Долгий сбор информации**: ручной поиск и сводка
- **Разные форматы**: сложно сравнивать конкурентов
- **Недостаточная глубина**: нет системной рамки
- **Медленные отчёты**: много ручной работы от данных к тексту

### Сценарии

- Продуктовые менеджеры: рынок и бенчмаркинг
- Инвесторы: картина конкуренции в отрасли
- Стартапы: дифференциация
- Консультанты: отраслевые отчёты

## ✨ Основные функции

### Общее (обе парадигмы)

- [x] **Сбор информации**: продукт, цены, отзывы и др.
- [x] **Структурирование**: очистка, категоризация, единая рамка сравнения
- [x] **Многомерный анализ**: функции, UX, позиционирование, бизнес-модель
- [x] **Отчёт**: резюме, детали, SWOT, стратегические рекомендации

### Сравнение парадигм

| Свойство | SimpleAgent | PlanAndSolveAgent |
|------|-------------|-------------------|
| **Работа** | Прямой ответ и инструменты | План, затем шаги |
| **Планирование** | Неявное | Явный список шагов |
| **Процесс** | Один или несколько вызовов | Шаг за шагом с историей |
| **Прозрачность** | Относительно «чёрный ящик» | Каждый шаг виден |
| **Сценарии** | Быстрые запросы | Сложный многошаговый анализ |
| **Время** | Быстрее (30–60 с) | Средне (60–120 с) |

**Когда что выбирать:**
- **Быстрый результат** → **SimpleAgent**
- **Глубина и контроль шагов** → **PlanAndSolveAgent**

## 📖 Примеры

### Пример 1: SimpleAgent — быстрый анализ

В `ProductAnalysis_SimpleAgent.ipynb` выполните ячейки:

```python
from hello_agents import SimpleAgent, HelloAgentsLLM
from hello_agents.tools import Tool, ToolParameter

llm = HelloAgentsLLM()

agent = SimpleAgent(
    name="Эксперт по конкурентному анализу",
    llm=llm,
    system_prompt="Вы профессиональный аналитик конкурентов..."
)

agent.add_tool(CompetitiveInfoSearchTool())
agent.add_tool(DataProcessorTool())
agent.add_tool(ReportGeneratorTool())

result = agent.run("Сравните Notion, Obsidian и Logseq")
print(result)
```

**Особенности:**
- Прямой ответ на запрос
- Автовызов инструментов
- Быстрый отчёт

---

### Пример 2: PlanAndSolveAgent — глубокий анализ

В `ProductAnalysis_PlanSolveAgent.ipynb`:

```python
from hello_agents.agents.plan_solve_agent import PlanAndSolveAgent

agent = PlanAndSolveAgent(
    name="Plan-and-Solve эксперт по конкурентам",
    llm=llm,
    system_prompt="Вы профессиональный аналитик конкурентов...",
    custom_prompts={
        "planner": "Промпт планировщика...",
        "executor": "Промпт исполнителя..."
    }
)

result = agent.run("Сравните Notion, Obsidian и Logseq")
print(result)
```

**Особенности:**
- Сначала план
- Пошаговое выполнение
- Прозрачный процесс

## 🎯 Преимущества

### 1. Две парадигмы агента

**SimpleAgent:**
- Быстрый отклик без лишнего планирования
- Простота использования
- Эффективен для быстрых запросов

**PlanAndSolveAgent:**
- Прозрачные шаги, удобно отлаживать
- Полнота за счёт явного плана
- Лучше для многошаговых задач

### 2. Модульная цепочка инструментов

Три группы (сбор, обработка, отчёт), расширяемые:
- `CompetitiveInfoSearchTool`
- `DataProcessorTool`
- `ReportGeneratorTool`

### 3. Несколько источников

- **Tavily Search API** (рекомендуется)
- **DuckDuckGo** без ключа
- Перекрёстная проверка данных

### 4. Структурированный вывод

- Резюме
- Матрица сравнения
- SWOT
- Рекомендации

### 5. Гибкая настройка

- Разные LLM
- Свои измерения анализа
- Tavily или DuckDuckGo
