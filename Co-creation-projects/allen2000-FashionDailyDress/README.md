# 🌤️ Мультиагентная система советов по одежде с учётом погоды

Система запроса погоды и рекомендаций по одежде на Python и Gradio с совместной работой нескольких агентов.

## 🎯 Описание проекта

Интеллектуальная система советов по одежде; несколько агентов обрабатывают запрос:
- **Агент погоды**: актуальные данные о погоде
- **Агент одежды**: профессиональные рекомендации по погоде
- **Координатор**: распределение задач между агентами

## ✨ Основные возможности

- 🌤️ **Погода в реальном времени**: крупные города мира
- 🤖 **Рекомендации ИИ**: советы по температуре, влажности, ветру
- 🔄 **Мультиагентность**: совместная обработка сложных запросов
- 🌐 **Веб-интерфейс**: Gradio

## 🚀 Быстрый старт

### 1. Подготовка окружения

```bash
git clone <repository-url>
cd bill-FashionDailyDress

pip install -r requirements.txt
```

### 2. Переменные окружения

Создайте `.env`:

```env
# LLM (обязательно)
LLM_API_KEY=your_llm_api_key
LLM_BASE_URL=your_llm_base_url
LLM_MODEL_ID=your_llm_model_id

# Погода (опционально, реальные данные)
OPENWEATHER_API_KEY=your_openweather_api_key
```

### 3. Запуск

#### Gradio (рекомендуется)
Python 3.12.10
```bash
python gradio_app.py
```
Откройте http://localhost:8899

#### Командная строка
```bash
python simple_multi_agent.py
```

## 🔧 Модули

### fashion_agent.py
- Профессиональный агент советов по одежде
- Учитывает температуру, влажность, ветер
- Одежда, аксессуары, замечания

### multi_agent_coordinator.py
- Координация агентов погоды и одежды
- Запрос → погода → совет → итог

### gradio_app.py
- Веб-интерфейс, примеры запросов
- Порт: 8899

### weather.py
- Обёртка погоды: API или демо-режим
- OpenWeatherMap API
