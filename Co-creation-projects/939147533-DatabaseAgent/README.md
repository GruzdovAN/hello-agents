# Помощник-агент для баз данных

Интеллектуальный помощник для запросов к БД на базе библиотеки hello-agents: преобразует естественный язык в SQL и получает данные из Oracle.

## 📝 Описание проекта

- На входе — естественный язык; автоматически генерируется SQL и выполняется запрос
- Поддержка Oracle с форматированным выводом результатов
- Подходит нетехническим пользователям и помогает разработчикам быстро получать SQL

## ✨ Основные возможности

- **Естественный язык → SQL**: опишите запрос на русском/китайском — получите SQL
- **Запросы к Oracle**: выполнение запросов и возврат результатов


##  🛠️ Технологический стек

Реализация на базе фреймворка ReAct (ReAct) из проекта HelloAgentsLearn:

- **ReAct Agent**: цикл рассуждение — действие
- **Tool Registry**: регистрация и управление инструментами
- **LLM Integration**: интеграция с большой языковой моделью
- **Oracle DB**: подключение и запросы к Oracle

## Реализация инструментов

1. **GetSchema**: получение структуры таблиц БД
2. **GenerateSQL**: преобразование естественного языка в SQL
3. **ExecuteQuery**: выполнение SQL и возврат результата

## 🚀 Быстрый старт
### Требования

- Python 3.10+
### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка API-ключей

1. Скопируйте пример конфигурации:
```bash
cp .env.example .env
```

2. Отредактируйте файл `.env` и укажите параметры:

### Конфигурация LLM
- `LLM_MODEL_ID`: ID модели, например `qwen3.6:35b-a3b-q4_K_M`
- `LLM_API_KEY`: API-ключ
- `LLM_BASE_URL`: адрес API-сервиса

### Конфигурация Oracle
- `DB_HOST`: хост БД
- `DB_PORT`: порт (по умолчанию: 1521)
- `DB_SERVICE_NAME`: имя сервиса
- `DB_USERNAME`: имя пользователя
- `DB_PASSWORD`: пароль


### Создание тестовых данных
Используйте прилагаемый SQL-скрипт:

```bash
# В Oracle SQL*Plus или другом клиенте
sqlplus username/password@host:1521/service_name @setup_database.sql
# Например:
sqlplus system/password@localhost:1521/ORCL @setup_database.sql
```
### Запуск проекта

#### Тестовая программа
python test.py

#### Основная программа:

```bash
python main.py
```
