# Умный наставник по программированию (Intelligent Programming Tutor)

Система обучения программированию на фреймворке HelloAgents с персонализированным опытом.

## Возможности

### 🎯 Основное

- **План обучения**: индивидуальный маршрут по целям и уровню
- **Умная генерация задач**: упражнения по текущей теме
- **Ревью кода**: профессиональная оценка, рекомендации и лучшие практики

### 🤖 Мультиагентная архитектура

Проект использует совместную работу агентов (Agent):

- **TutorAgent (наставник)**: координатор, понимает запрос и вызывает подагентов
- **PlannerAgent (планировщик)**: персональный план и траектория
- **ExerciseAgent (автор задач)**: генерация упражнений
- **ReviewerAgent (рецензент)**: обратная связь по коду, с запуском для проверки

## Установка и настройка

### 1. Требования

- Python 3.8+
- Фреймворк HelloAgents

### 2. Зависимости

```bash
pip install -r requirements.txt
```

### 3. Переменные окружения

Создайте `.env`:


Полный список опций — в `.env.example`.

## Использование

### Вариант 1: Jupyter Notebook

Откройте `main.ipynb` и выполните ячейки по порядку:

1. План обучения
2. Упражнения
3. Ревью кода

### Вариант 2: Python

```python
from hello_agents import HelloAgentsLLM
from src.agents.tutor import TutorAgent

# Инициализация LLM
llm = HelloAgentsLLM.from_env()

# Наставник
tutor = TutorAgent(llm)

# Пример 1: план обучения
response = tutor.run("Хочу изучить list comprehension в Python")
print(response)

# Пример 2: упражнение
response = tutor.run("Дай задачу по list comprehension")
print(response)

# Пример 3: ревью кода
code = """
numbers = [1, 2, 3, 4, 5]
squares = []
for n in numbers:
    squares.append(n * n)
"""
response = tutor.run(f"Проверь код: {code}")
print(response)
```

## Техническая архитектура

### Взаимодействие агентов

- Режим **Agent-to-Agent (A2A)** через инструменты
- `TutorAgent` вызывает подагентов:
  - `call_planner(query)` — планировщик
  - `call_exercise(query)` — автор задач
  - `call_reviewer(query)` — рецензент

### Запуск кода

`ReviewerAgent` использует `CodeRunner`:
- Безопасное выполнение Python-кода пользователя
- Перехват ошибок выполнения
- Более точная обратная связь по результатам запуска

## Примеры сценариев

### Сценарий 1: план обучения

**Ввод пользователя:**
```
Хочу изучить декораторы в Python, знаю только базовые функции
```

**Ответ системы:**
Наставник вызовет PlannerAgent и сформирует план:
- Проверка предварительных знаний
- Поэтапные цели
- Рекомендуемые материалы
- Практические проекты

### Сценарий 2: упражнение

**Ввод:**
```
Дай задачу по декораторам
```

**Ответ:**
ExerciseAgent сформирует задачу с описанием, примерами ввода/вывода, уровнем сложности и проверяемыми темами.

### Сценарий 3: ревью кода

**Ввод:**
```python
@decorator
def greet(name):
    print(f"Hello, {name}")
```

**Ответ:**
ReviewerAgent:
1. Запустит код и проверит синтаксис/ошибки
2. Оценит качество и практики
3. Предложит улучшения
4. Укажет потенциальные проблемы
