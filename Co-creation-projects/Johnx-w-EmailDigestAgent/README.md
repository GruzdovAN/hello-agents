# Умный дайджест почты (EmailDigestAgent)

> Система обработки почты на HelloAgents: загрузка входящих, ИИ-классификация и сводка, ежедневный отчёт — без перегруженного inbox

## 📝 О проекте

Каждое утро — десятки непрочитанных писем: что срочно, что отложить, что мусор?

**EmailDigestAgent** решает эту задачу: забирает входящие, классифицирует и кратко излагает каждое письмо через большую модель, собирает структурированный «почтовый дайджест» — обзор inbox за ~5 минут.

**Решаемые проблемы:**
- 📧 Скопление писем, долгий ручной отбор
- 🔍 Важное теряется среди уведомлений, рекламы и спама
- ⏰ 30–60 минут каждое утро на почту
- 📊 Нет общей картины и приоритетов

**Особенности:**
- 🤖 Сводки от большой модели, а не обрезка первых строк
- 🏷️ Автоклассификация (работа / клиенты / личное / уведомления / спам)
- 📊 Структурированный Markdown-дайджест
- 🔗 Реальный IMAP или демо на симулированных данных
- 🪶 Лёгкий pipeline: получение → классификация → сводка → отчёт

## ✨ Основные возможности

## 🔧 Настройка реального ящика (IMAP)

Поддерживаются QQ / 163 / 126 / Gmail / Outlook и любые ящики с IMAP.

### Включение IMAP и пароль приложения

| Почта | IMAP-сервер | Порт | Как включить |
|------|------------|------|---------|
| QQ | imap.qq.com | 993 | Настройки → Учётная запись → IMAP/SMTP → пароль приложения |
| 163 | imap.163.com | 993 | Настройки → POP3/SMTP/IMAP → IMAP → пароль приложения |
| 126 | imap.126.com | 993 | Как у 163 |
| Gmail | imap.gmail.com | 993 | Google Account → Безопасность → 2FA → пароль приложения |
| Outlook | outlook.office365.com | 993 | Microsoft Account → Безопасность → пароль приложения |

### Настройка (один из способов)

**Способ 1 (рекомендуется):** в `.env` укажите `IMAP_SERVER` / `IMAP_PORT` / `IMAP_USERNAME` / `IMAP_PASSWORD`.

**Способ 2:** в `config/email_config.json` измените секцию `imap`.

После настройки `use_demo=False` переключает на реальный режим. При ошибке подключения будет явное сообщение с причиной.

- **Реальная боль**: перегруженный inbox у каждого в офисе
