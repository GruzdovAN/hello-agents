# DataAnalysisAgent — интеллектуальный помощник по анализу данных

> Интеллектуальный инструмент анализа данных на базе фреймворка HelloAgents

## 📝 Описание проекта

DataAnalysisAgent — интеллектуальный помощник по анализу данных: автоматически анализирует данные, строит визуализации и формирует аналитические отчёты.

### Основные возможности

- ✅ Анализ данных: статистика трендов, выбор подходящих диаграмм и т.д.
- ✅ Интеллектуальные рекомендации: на основе LLM — код визуализаций и аналитический отчёт
- ✅ Генерация отчётов: анализ в формате Markdown

## 🛠️ Технологический стек

- Фреймворк HelloAgents (SimpleAgent)
- Модуль Python AST (разбор кода)
- OpenAI API (интеллектуальный анализ)

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка параметров LLM

**Способ 1: файл .env (рекомендуется)**

```bash
# Скопировать пример
cp .env.example .env

# Отредактировать .env и указать конфигурацию
# LLM_MODEL_ID=Qwen/Qwen2.5-72B-Instruct
# LLM_API_KEY=your_api_key_here
# LLM_BASE_URL=https://api-inference.modelscope.cn/v1/
```

**Способ 2: настройка прямо в Notebook (уже настроено)**

В `main.ipynb` преднастроен API ModelScope — можно использовать сразу. Для изменения отредактируйте код конфигурации в части 1:

```python
os.environ["LLM_MODEL_ID"] = "your_model"
os.environ["LLM_API_KEY"] = "your_key"
os.environ["LLM_BASE_URL"] = "your_api_url"
```

### Запуск проекта

```bash
jupyter lab
# Откройте main.ipynb и выполните все ячейки
```
