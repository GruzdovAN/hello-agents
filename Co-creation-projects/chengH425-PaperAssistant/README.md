# PaperAssistant — умный помощник по научным статьям

> Мультиагентный академический инструмент на HelloAgents + DeepSeek: 6 источников данных — поиск литературы, резюме, ссылки, редактура, план, написание и обработка PDF.

## 📝 О проекте

PaperAssistant для аспирантов и исследователей: мультиагентное взаимодействие от обзора литературы до написания текста.

### Какие задачи решает?

- Долгий поиск, узкое покрытие одной БД → **6 источников на выбор**
- Много чтения, сложно выделить суть → **структурированное резюме LLM**
- Сложные форматы ссылок → **GB/T 7714 / APA / MLA в один клик**
- Много правок при редактуре → **многоходовая редактура с памятью контекста**
- Трудно составить план → **пошаговое построение оглавления**
- Сложно писать текст → **главы по плану со ссылками на реальные источники**

## ✨ Основные функции

- [x] **Поиск литературы**: 6 источников (Semantic Scholar / AMiner / OpenAlex / PubMed / CrossRef / arXiv), фильтры по дисциплине и году
- [x] **Резюме статьи**: ключевые идеи, методы, выводы
- [x] **Генерация ссылок**: GB/T 7714, APA 7th, MLA 9th
- [x] **Редактура**: многоходовый диалог с памятью контекста
- [x] **План (оглавление)**: уточнение в диалоге
- [x] **Написание**: по главам с реальными ссылками (без выдумок AI)
- [x] **PDF → Markdown**: загрузка PDF, распознавание структуры, конвертация
- [x] **Gradio Web UI**: 8 вкладок + автосохранение диалогов и история сессий

## 🛠️ Стек технологий

| Уровень | Технологии |
|------|------|

## 📖 Описание функций

### Вкладки (8)

| Вкладка | Функция | Реализация |
|--------|------|---------|
| 📚 Поиск литературы | 6 источников + фильтры + повтор API | SimpleAgent + маршрутизация инструментов |
| 📝 Резюме | Структурированное резюме по тексту | SimpleAgent |
| 📎 Ссылки | 3 формата из формы | CitationTool (детерминированно) |
| ✍️ Редактура | Многоходовый диалог + история | SimpleAgent |
| 📊 План | Построение оглавления + история | SimpleAgent |
| 📝 Написание | Главы по плану + реальные ссылки | SimpleAgent + 5 поисковых инструментов |
| 📄 PDF → Markdown | Заголовки/разделы/абзацы | PDFExtractTool |
| 💬 История | Автосохранение, удаление записей | JSON + HTML-карточки |

### Сравнение 6 источников

| Источник | Объём | Дисциплины | Особенности |
|--------|:-----:|---------|------|
| Semantic Scholar | 200M+ | Все | Рекомендуется, широкое покрытие |
| AMiner | 320M+ | Все | Сильнее всего по китайским статьям |
| OpenAlex | 250M+ | Все | Открытый доступ, агрегация |
| PubMed | 36M+ | Биомедицина | Авторитет в медицине |
| CrossRef | 150M+ | Все | Полные метаданные журналов |
| arXiv | 2.4M+ | CS/мат/физ | Быстрые препринты |
