# Банк практических задач по программированию (Practice Question Bank)

Этот репозиторий содержит **данные банка задач по программированию**, используемые интеллектуальной системой-наставником для поддержки поиска и генерации упражнений на основе RAG (retrieval-augmented generation).

## 📦 Описание данных

Банк задач предназначен для следующих сценариев:
- поиск подходящих упражнений по программированию в соответствии с учебным планом и текущим этапом обучения;
- поддержка разных уровней сложности;
- использование в качестве офлайн-источника знаний для интеллектуальной системы-наставника.

Подробное описание структуры задач и полей см. в модулях загрузки и разбора данных в коде проекта.

## 📁 Способ использования

1. Скачайте и распакуйте данные банка задач
2. Поместите директорию с данными в указанный путь проекта (например, `data/`)
3. Укажите путь к банку задач в коде `exercise.py`
4. Запустите систему — модуль RAG сможет выполнять поиск задач
