# TutorAgent

> Интеллектуальная система-наставник по программированию на основе мультиагентного взаимодействия: планирование учебного пути, генерация задач через RAG, ревью кода и обзор учебной памяти.

---

## 📝 О проекте

**TutorAgent** — интеллектуальная система-наставник по программированию на основе LLM и архитектуры мультиагентного взаимодействия (Agent-to-Agent, A2A). Она имитирует учебный процесс «живого наставника» и даёт пользователю **непрерывный, обозримый и развивающийся** опыт обучения программированию.

## ✨ Основные возможности

- [x] **Планирование учебного пути (PlannerAgent)**  
  Автоматически формирует структурированный учебный план (Markdown) по целям и текущему уровню пользователя; поддерживает динамическое обновление прогресса по этапам.

- [x] **Интеллектуальная генерация задач (ExerciseAgent + RAG)**  
  На основе RAG извлекает из банка задач упражнения, соответствующие текущему этапу обучения и уровню сложности.

- [x] **Ревью кода и обратная связь (CodeReview-Agent)**  
  Автоматически анализирует отправленный код и запускает тесты; формирует профессиональную обратную связь по корректности, стилю и сложности.

- [x] **Учебная память и обзор (Memory + NoteTool)**  
  Сохраняет учебную активность, прогресс по этапам и ключевые темы; поддерживает состояние между сессиями и запросы на обзор на естественном языке.

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- настроенный LLM API Key (или локальная модель)

```bash
# Создать файл переменных окружения
cp .env.example .env

# Указать LLM API Key в .env
python main.py
```

Ввод пользователя:
```
Хочу изучить list comprehensions в Python
```

Поведение системы:
- PlannerAgent формирует учебный план и сохраняет его как учебную заметку
- Memory фиксирует учебную цель
- позже можно запросить обзор фразой «хочу вспомнить учебные цели»

Ввод пользователя:
```
Хочу обновить учебный план
```

Поведение системы:
- автоматически обновляет прогресс учебного плана
- помечает соответствующий этап как завершённый [x]
