# Интеллектуальный помощник по анализу акций

Инструмент инвестиционного анализа акций A-share на базе **фреймворка мультиагентного взаимодействия HelloAgents**: котировки, финансовый анализ, новостной сентимент, умный скрининг, симуляция сделок и прочее — для поддержки решений на основе данных.

> ⚠️ **Отказ от ответственности**: все результаты анализа **не являются инвестиционной рекомендацией**. Инвестиции связаны с риском — действуйте осознанно.

## Особенности проекта

- **Мультиагентное взаимодействие**: **Reflection** (оценка Баффета) + **ReAct** (Reasoning + Acting — сентимент/данные/советник) + **маршрутизация координатором**; вкладки анализа акции запускают агентов независимо с потоковым выводом; чат-ассистент вызывает под-агентов по необходимости. Скрининг, избранное и симуляция — backend Service **напрямую к `skills/`**, без отдельных агентов
- **ИИ-чат-ассистент**: одно решение маршрутизации LLM (`data` / `sentiment` / `advisor` и комбинации), под-агенты **без потока**, затем координатор собирает ответ; одна размерность — прямой вывод, несколько — **потоковый** синтез LLM (лимиты длины, см. `agents/coordinator_agent.py`, `agents/text_truncation.py`)
- **Потоковый ИИ-анализ**: сентимент, данные и Баффет — NDJSON, отображение генерации в реальном времени
- **Рамка стоимостного инвестирования Баффета**: 8 справочных документов, ReflectionAgent улучшает отчёт
- **Файловый кэш**: данные по акции на диске, сначала кэш, затем API; grep-поиск
- **Персонализация**: предпочтения через `preference_service` и `/api/v1/preferences`
- **Полный стек**: Vue3 + FastAPI + HelloAgents + данные East Money MX
- **Безопасность операций**: симуляция сделок и удаление из избранного — с подтверждением

## Быстрый старт

### Требования

- Python ≥ 3.10
- Node.js ≥ 18
- Docker ≥ 24 (опционально, продакшен)

### Переменные окружения

Скопируйте `.env.example` в `.env` и укажите ключи. **Для локальной разработки оставьте `BACKEND_PORT=8000`** (как proxy в `frontend/vite.config.js`); для exe можно `5174`. Основные параметры (полный список — в комментариях `.env.example`):

```env
# LLM (совместим с HelloAgents)
LLM_MODEL_ID=deepseek-chat
LLM_API_KEY=sk-your-deepseek-key
LLM_BASE_URL=https://api.deepseek.com
# Опционально: таймаут одного запроса (сек); backend объединяет с большим нижним пределом,
# чтобы ReAct/многоходовый чат не обрывался рано
# LLM_TIMEOUT=180

# Оценка Баффета: опционально число раундов рефлексии (BUFFETT_MAX_REFLECTIONS в .env.example)

# Финансовые данные East Money MX
MX_APIKEY=your-mx-apikey
# Опционально: MX_API_URL, MX_CACHE_TTL_SECONDS, локальный replay MX_REPLAY_FIXTURES и др.

# Порт: в dev по умолчанию 8000; PyInstaller exe — 5174 (как в run_exe.py)
# При смене BACKEND_PORT обновите proxy /api в frontend/vite.config.js
```

> 💡 DeepSeek API: https://platform.deepseek.com  
> 💡 MX API: https://dl.dfcfs.com/m/itc4  

### Локальная разработка

**Backend**:

```bash
# Зависимости (эквивалент: pip install -r requirements.txt из корня репозитория)
pip install -r backend/requirements.txt

# Запуск (из корня проекта)
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

Документация API: http://localhost:8000/docs

**Frontend**:

```bash
cd frontend
npm install
npm run dev
```

Интерфейс: http://localhost:5173 (dev проксирует `/api` на порт 8000)

### Развёртывание в Docker

```bash
docker compose up -d
```

- Frontend: http://localhost:8080
- Backend API: http://localhost:8000/docs

Подробности: [DEPLOY.md](./DEPLOY.md)

| Компонент | Назначение | Только для сборки? |


## Потоки взаимодействия агентов

### ИИ-чат-ассистент

```
Сообщение пользователя
    │
    ▼
Координатор (маршрутизация LLM, одна строка-ключ)
    │ none → обычный диалог (поток LLM координатора или подсказка по контексту акции)
    │ data / sentiment / advisor или комбинации
    ▼
Под-агенты последовательно (без потока, лимит длины)
    ├── data → run_data_analysis
    ├── sentiment → run_sentiment
    └── advisor → сводки data/sentiment в prompt → run_advisor
    │
    ▼
Потоковый ответ пользователю
    ├── один под-агент → прямой вывод (с обрезкой)
    └── несколько → stream_invoke координатора, структурированный ответ
```

### Оценка по Баффету

```
Пользователь: «Сгенерировать отчёт Баффета»
    │
    ▼
advisor_agent (ReflectionAgent)
    │ сбор котировок/финансов/сентимента
    ├── начальный анализ → ров / менеджмент / запас прочности
    ├── саморефлексия → точность данных / логика
    └── итерации → доработка отчёта
    │
    ▼
Потоковый финальный отчёт + сохранение в историю
```

### Разделение бизнес-API и агентов

| Возможность | Реализация |
|------|----------|
| ИИ-сентимент / данные / чат / Баффет | `agents/*` + HelloAgents (ReAct / Reflection / координатор) |
| Скрининг / избранное / симуляция / котировки и новости | `backend/app/services/*` → `skills/*` (MX API) |
| Предпочтения | `preference_service` + `/api/v1/preferences` |

## Файловый кэш

Данные по акции сохраняются в `data/stock_cache/{код_акции}/`:

```
data/stock_cache/
  _index.json           # Главный индекс
  600519/
    quote.json          # Котировки
    financial.json      # Финансы
    profile.json        # Профиль
    holders.json        # Топ-10 акционеров
    sentiment.json      # Сентимент
    news.json           # Связанные новости (если есть)
```

- Кэш за текущий день отдаётся без почасового лимита; при смене дня данные старше 24 ч истекают
- API вызывается только при промахе кэша, результат пишется в файл
- `GET /api/v1/cache/search?keyword=600519` — поиск в стиле grep
- Кэш сохраняется после перезапуска сервиса
