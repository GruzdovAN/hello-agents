## 📖 О проекте

InnoCore AI (Исследования·Интеллектуальное ядро) — интеллектуальная система-помощник для научных исследований, построенная на фреймворке HelloAgent. Благодаря мультиагентному взаимодействию она автоматизирует весь цикл: от поиска статей и глубокого анализа до помощи в написании и проверки ссылок.

### Ключевые возможности

- 🤖 **Мультиагентное взаимодействие**: четыре агента (Hunter/Miner/Coach/Validator) работают совместно
- 🔄 **Два режима**: отдельный (точный контроль) + координирующий (всё в один клик)
- 📚 **Интеллектуальный анализ статей**: автоматический разбор PDF, извлечение ключевой информации, формирование отчётов
- ✍️ **AI-помощник по написанию**: академическая редактура, смена стиля, подсказки в реальном времени
- 🔍 **Умная проверка ссылок**: автоматическое распознавание DOI/ArXiv ID, генерация ссылок в разных форматах
- 🎯 **Автоматизация рабочего процесса**: поиск → анализ → ссылки → отчёт в один клик

### Технические особенности

- **Глубокий разбор PDF**: структурированное извлечение из научных статей (заголовок, авторы, аннотация, полный текст)
- **Гибридный поиск**: векторный поиск + сопоставление по ключевым словам для повышения точности
- **Потоковый вывод**: передача в реальном времени через WebSocket
- **Асинхронная архитектура**: FastAPI, высокая производительность при параллельной обработке
- **Модульный дизайн**: чёткая слоистая архитектура, легко расширять и поддерживать

## 🎯 Сценарии применения

### Кому подойдёт?

- 📖 **Аспиранты и докторанты**: быстрое погружение в область, помощь в написании статей
- 👨‍🏫 **Преподаватели вузов**: отслеживание новых исследований, подготовка заявок на гранты
- 🔬 **Сотрудники R&D в компаниях**: технологический обзор, анализ патентов, исследование конкурентов
- 📝 **Академические авторы**: редактура, управление ссылками, соблюдение форматов

### Типичные сценарии

1. **Обзор литературы**: автоматический поиск → пакетный анализ → отчёт-обзор
2. **Написание статьи**: подсказки по редактуре → автогенерация ссылок → проверка формата
3. **Исследовательский обзор**: отслеживание темы → выявление новизны → рекомендации по направлениям
4. **Академический перевод**: перевод EN↔ZH → оптимизация академической лексики → стандартизация терминов

### Четыре агента

| Агент | Задачи | Ключевые возможности |
|--------|------|----------|
| 🕵️ **Hunter** | Поиск и мониторинг статей | Поиск в ArXiv/IEEE в реальном времени, умная фильтрация, автозагрузка |
| 🧠 **Miner** | Глубокий анализ и извлечение | Разбор PDF, выделение новизны, сравнительный анализ, отчёты |
| ✍️ **Coach** | Помощь в написании и редактуре | Академическая редактура, смена стиля, подсказки, оптимизация терминов |
| 🔎 **Validator** | Проверка и форматирование ссылок | Проверка DOI, несколько форматов, валидация метаданных, стандартизация |

## Быстрый старт

### 1. Установка

```bash
# Установка основных зависимостей
python install.py

# Или вручную
pip install fastapi uvicorn python-multipart python-dotenv pydantic httpx requests
```

### 2. Конфигурация

Создайте файл `.env`:
```bash
cp .env.example .env
# Отредактируйте .env и добавьте ключ OpenAI API
```

### 3. Запуск

```bash
python run.py
```

### 4. Доступ

- Основное приложение: http://localhost:8000
- Документация API: http://localhost:8000/docs
- Проверка состояния: http://localhost:8000/health

## Возможности

### Режимы работы

- **Отдельный режим**: каждый агент (Agent) используется независимо для конкретных задач
- **Режим рабочего процесса** ⭐: автоматический полный цикл с координацией всех агентов

### Агенты

- 🕵️ **Hunter Agent**: поиск и мониторинг литературы
- 🧠 **Miner Agent**: глубокий анализ статей и извлечение инсайтов
- ✍️ **Coach Agent**: помощь в написании и улучшение стиля
- 🔎 **Validator Agent**: проверка и форматирование ссылок

### Автоматизация рабочего процесса

Полный исследовательский цикл в один клик:
1. Поиск статей (Hunter)
2. Анализ содержания (Miner)
3. Генерация ссылок (Validator)
4. Создание отчёта (Coach)

## 📊 Показатели производительности

- **Поиск статей**: ~5 с (время ответа ArXiv API)
- **Разбор PDF**: ~3 с/статья (стандартная академическая статья)
- **Глубокий анализ**: ~20 с/статья (с выводом AI)
- **Редактура текста**: ~2 с до первого токена (потоковый вывод)
- **Проверка ссылок**: ~3 с/запись (с внешней проверкой API)
- **Полный рабочий процесс**: ~70 с (поиск 3 статей + анализ + ссылки + отчёт)
