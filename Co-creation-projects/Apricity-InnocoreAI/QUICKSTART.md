# InnoCore AI — Краткое руководство по запуску

## 🚀 Быстрый старт

### 1. Подготовка окружения
Убедитесь, что установлен Python 3.8 или выше.

### 2. Установка зависимостей
```bash
cd innocore_ai
python setup.py
```

### 3. Настройка переменных окружения
Отредактируйте файл `.env` и добавьте ваш OpenAI API Key:
```bash
OPENAI_API_KEY=your_actual_openai_api_key_here
```

### 4. Запуск приложения
```bash
python run.py
```

### 5. Доступ к приложению
- Главная страница: http://localhost:8000
- Документация API: http://localhost:8000/docs
- Проверка работоспособности: http://localhost:8000/health

## 📋 Возможности

### 🤖 Система агентов
- **Hunter Agent**: поиск и мониторинг литературы
- **Miner Agent**: глубокий анализ статей
- **Coach Agent**: помощь в написании текстов
- **Validator Agent**: проверка цитирования

### 🔧 Основные функции
- Автоматический сбор литературы
- Интеллектуальный анализ статей
- Помощник для академического письма
- Управление форматами цитирования

## 🛠️ Режим разработки

Для режима разработки с автоперезагрузкой измените в `run.py` значение `reload=False` на `reload=True`.

## 📞 Устранение неполадок

### Частые проблемы

1. **Порт занят**
   - Измените номер порта в `run.py`
   - Или остановите программу, занимающую порт 8000

2. **Ошибка OpenAI API Key**
   - Убедитесь, что API Key в `.env` указан верно
   - Проверьте, что ключ действителен и на счёте достаточно средств

3. **Не удалось установить зависимости**
   - Попробуйте обновить pip: `pip install --upgrade pip`
   - Или используйте виртуальное окружение
